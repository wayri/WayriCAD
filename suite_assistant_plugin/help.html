WayriCAD Assistant

Use ordinary language to run supported WayriCAD checks. Choose Local commands or an optional Ollama model on your own computer. No cloud, automatic model downloads or layout edits are enabled.

Ollama: ask, review, run, interpret

  1. Install Ollama and a model separately, then start its local service.
  2. Choose Ollama (review before Run) and click Find models. Select an already installed model. The default endpoint is http://127.0.0.1:11434; only loopback HTTP is allowed.
  3. Ask a question, for example Calculate microstrip impedance width 0.2 mm height 0.1 mm er 4.2. Review every action and numerical input. Supply missing fields in Plan & inputs.
  4. Click Run plan. LLM proposals never auto-run, even when automatic read-only execution is enabled. Existing tool adapters, sealed plans and saved-source hash checks remain authoritative.
  5. After a run, click Interpret results. This sends bounded, hash-verified numerical JSON to local Ollama and displays a separate explanation with evidence IDs and provenance. Tool statuses and numbers are not changed.

AI interpretation is not engineering validation. Model inputs and prose can be wrong. Review units, unknowns, material properties, scope and model limitations. Every plugin in the CLI registry has registered actions, but this is not every GUI feature or autonomous Apply. The model cannot supply paths, arbitrary commands or switches. Enter required file inputs in the host clarification fields; apply design previews in their originating tool.

Only task text, selected net/reference names and action schemas are sent during planning. Interpretation sends numerical reports, which may include project metadata: use a trusted local service. Raw PCB bytes are not sent by the planner. Proxies and redirects are bypassed. No cloud endpoint, model download, service installation or automatic provider fallback is used. Missing Ollama leaves Local commands available. Select a model with at least 16,384 context tokens. Oversized evidence (96 KiB), malformed JSON, stale reports and unknown evidence IDs are rejected rather than silently truncated or accepted.

Use Cancel to interrupt a request. A service/model error is shown explicitly; start Ollama, choose an installed compatible model and retry. Changing the query, board selection or provider settings invalidates the old interpretation. Suggestions are not tool execution.

Correct a proposal: edit its values in Plan & inputs and click Use these inputs. Clear an optional value to omit it; unknown required values are requested again. Select an unwanted task and click Remove selected task. Editing disables Run until the correction is submitted. Small local models may invent defaults or add tasks: review all of them. No automatic execution means an interpretation mistake need not become a tool run.

Ask, supply inputs, inspect results

  1. Save the PCB and open the Assistant from its toolbar action, or choose a saved PCB.
  2. Type one check and click Ask Assistant. Try an example if you are unsure of the available wording.
  3. Read Plan & inputs. Missing inputs appear as editable fields. Invalid inputs show the reason beside the field and retain your entry for correction. Enter them and click Use these inputs. If several checks match, choose the intended one.
  4. A ready read-only plan runs automatically. Turn off automatic execution to inspect every plan and use Run plan yourself.
  5. Read Results & reports. Select an artifact and click Open selected report or double-click it. Reports are opened only when they exist inside the recorded results folder.

Visual workflow feedback

Native icons identify actions and tabs. The plan table lists each check, its target and its current state. The status badge and pulsing activity gauge show when work is running; the pulse is not a numerical completion percentage. Results count completed tasks, unresolved tasks and generated files.

Find saved results

Results persist under Documents/WayriCAD/Assistant/results. Each run has its own folder and its plan, run record and artifacts remain after you close the window. Use Results folder… to choose a different destination for future runs and Open results folder to open the current run in your file manager. Boolean input fields offer true and false; those words are accepted by the planner.

Select nets visually

Open Board selection and click Load board preview. This optional step avoids loading and drawing the full PCB during startup. Click a pad, via or trace to select its net. Only exact selected nets receive the accent highlight, including saved pad/via geometry and zone borders; unselected copper is dimmed. Zone borders are not rendered as invented filled copper. Use Add clicked nets to selection for multiple targets and Clear net selection to start again. Use Focus selected to fit matching saved items, Fit board to restore the full saved extent and Expand board for a larger viewport. Changing to another tab restores the query controls. The legend and net/item counts identify the highlighted data. Wheel to zoom, drag to pan and double-click to fit.

A selected net supplies context for a request that does not explicitly name a net. Selection changes invalidate the previous plan; ask again before running. The preview caches the saved board. Unsaved editor changes are not included; save, then choose the PCB again to refresh it.

Navigate to PCB Editor

Show in PCB Editor explicitly selects the chosen nets in the originating editor. It is never triggered merely by hovering or changing the preview. The saved hash is checked and the complete selection is confirmed; stale files or missing originating-editor context produce an actionable error. Camera focus is reported as requested or unavailable, not guaranteed. Matching the saved file does not validate unsaved live geometry. No design objects are edited.

The navigation path was validated with native UI mocks and shared context/staleness/rollback tests. An installed live-toolbar session was not available during this check.

Missing inputs and numerical honesty

The planner asks for required nets, units and numerical inputs instead of inventing simulation settings. An ambiguous match is offered for user selection. Unsupported requests are reported without trying an unrelated command. Returned values retain the original tool’s limitations, material assumptions and boundary conditions.

Supported commands

Run python -m suite_assistant_plugin capabilities for the exact catalogue. To count fitted nominal values ask Give me the number of 10u capacitors with a saved project; or ask Give me layer wise total copper area with a saved PCB. Unknown saved geometry and zone fill are not counted as zero.

For steady spatial screening ask Solve board heat map at 25 C with C1=0.5 W. This uses an automatically meshed thin sheet and declared still-air defaults, not junction temperatures. PI AC ports, DC bundles and reviewed series paths, SI multi-net studies, and thermal component RC/3D studies accept their native reviewed JSON files in the host input form. PI tree and path discovery can run directly; edit paths in Quick PI.

Ask List EMerge examples, then request a run by exact example ID. This requires a prepared qualified solver and uses the built-in geometry rather than the selected PCB layout. Custom studies and full field visualization remain in Quick EMerge. Open large solver reports directly when they exceed the interpretation budget.

Files, privacy and cancellation

The saved design is read-only. Outputs go into a separate results folder. Opening or closing the Assistant does not alter component placement, copper, zones or annotations. Closing requests cancellation and discards queued window callbacks. The execution broker remains alive long enough to stop its worker and record the cancelled run before the process exits. The command engine constructs argument arrays for registered tools; user text is not executed as a shell command.

Generated reports may contain board names, references and nets from the selected design. Review them before sharing. Dependencies for the invoked tool may need a one-time runtime setup; the fuzzy planner itself needs no network access.
