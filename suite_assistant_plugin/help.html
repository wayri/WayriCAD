WayriCAD Assistant

Ask for a check, simulation or plugin in the chat. The Assistant matches local phrases to registered WayriCAD actions.

Choose circuit names as you type

Choose a saved PCB. When a net, part or pad suggestion appears, use the arrow keys and Tab, or double-click a row. The indexed names and copper preview come from the saved PCB. Save editor changes before running.

Set up and run

  1. Describe the analysis and include any known values. For example, Quick PI voltage drop at 3.3 V from J1.1 to U1.1 with 250 mA.
  2. Review Plan & inputs in the lower pane. Reply to follow-up questions in chat or enter values in the form. Drag the divider to expand the lower pane.
  3. Click Run plan or type run for a ready simulation. Auto-run simple checks applies to ready non-simulation checks.
  4. Open files from Results & reports. Use Cancel to stop a running tool.

Choose the right study

Quick PI supports DC rail analysis and reviewed AC, transient, series, batch and electrothermal study files. Quick SI supports route screening and reviewed multi-net study files. QuickTherm supports component screening, a steady board heat map with explicit source watts, and reviewed transient and solid studies. Study material assumptions, loads, drivers and thermal boundary conditions remain part of the input.

Use List available tools for the registered catalogue. Ask Which plugin handles crosstalk? for tool guidance.

Review saved geometry and results

In Board selection, load the preview and click copper to select exact nets. Expand board temporarily enlarges that pane. Show in PCB Editor navigates the selected nets in the originating editor after checking the saved revision. Source files stay unchanged.

Runs retain their plans and reports under Documents/WayriCAD/Assistant/results by default. Use Results folder… to change the destination.

CLI

wayricad-assistant capabilities
wayricad-assistant plan "List available tools"
wayricad-assistant run plan.json --output-root results
