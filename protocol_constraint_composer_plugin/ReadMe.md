# KiWay Protocol Constraint Composer 0.1.0

Detects likely USB, CAN, Ethernet, PCIe/SerDes, DDR, RS-485, and RF nets from editable conventions and composes a reviewable KiCad custom-rule block. Export rules for inspection or apply only the delimited KiWay-managed section after a timestamped backup.

Preset geometry is illustrative and must be replaced with values derived from the actual stackup, protocol specification, device requirements and fabricator. Always use KiCad's rule syntax checker and DRC after applying rules.
