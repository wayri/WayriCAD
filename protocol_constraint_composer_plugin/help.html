Protocol Constraint Composer

Workflow

  1. Detect likely protocol nets from the current PCB.
  2. Review every protocol/net assignment.
  3. Generate and inspect the exact rule text.
  4. Export it, or apply the managed block after confirmation and backup.
  5. Open Board Setup, check rule syntax, then run DRC.

Safeguards

The plugin only replaces text between its managed markers. Existing rules outside that block remain untouched.

Limitations

Preset dimensions are starting points, not authoritative protocol values. Derive final dimensions from the actual stackup, device requirements and fabricator field-solver results.
