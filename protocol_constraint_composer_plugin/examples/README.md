# Demonstrations, not design specifications

Replace all names and dimensions with your own engineering intent. The rule
profiles and matrix contain illustrative values, not approved process limits.
The all-forms example is disabled; do not enable every rule as a board policy.

`profiles/` contains the six parameterized starter definitions (blank parameters).
`workflow_demo/` contains a synthetic BGA/attached-area preview fixture, not a
native-validated or fabrication-ready PCB. Its README explains intentional faults.
