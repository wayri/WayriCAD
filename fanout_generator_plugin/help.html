KiWay Fanout Generator

Annotated interface walkthrough

The numbered cues below match the visible workflow in the plugin. A preview is the review evidence; committing or exporting is the final step.

Creates conservative radial, BGA/LGA-grid, or perimeter escape tracks from SMD pads.

Cross-selection: Preview and Generate automatically select their tracks/vias. Use Select Generated later to reselect the current preview or most recent generated fanout.

Workflow

  1. Enter one footprint reference, or leave blank to process SMD footprints.
  2. Choose the pattern, pad layer/escape layer, width, length, clearance, and optional vias.
  3. Click Preview; the new geometry is selected in PCB Editor for inspection.
  4. Clear Preview or Generate. Run DRC and complete routing manually.

Guardrails

  • Specify a reference instead of processing all SMD footprints when scoping a sensitive area.
  • Reduce length or width if clearance violations appear.
  • This tool creates a starting escape pattern; it is not an autorouter and does not replace DRC review.
