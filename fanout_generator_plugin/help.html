KiWay Fanout Generator

Creates reviewable escape-routing starters from selected SMD pads on BGA, LGA, QFN, and peripheral packages.

Annotated interface walkthrough

Nothing reaches the PCB during Preview in Window. Show on PCB creates temporary selected geometry. Commit to PCB is the only action that keeps it.

Scopes and live selection

Choose selected pads, selected footprints, a reference wildcard, or all SMD pads. With auto-refresh enabled, PCB selection updates the window preview. Double-click a preview row to select that pad in PCB Editor.

Patterns

PatternPurpose
Dogbone outward/inwardPad-to-via escape away from or toward the package center.
BGA/LGA gridOrthogonal row/column escape for regular arrays.
QuadrantDiagonal escape by package quadrant.
Four-cornerRoutes pads toward or away from the nearest package corner.
Perimeter / radialOrthogonal edge or center-radial escape.
Via-in-padPlaces a via at the pad center; requires filled/capped-via fabrication support where applicable.

Four-stage workflow

  1. Configure scope, pattern, dimensions, layer, and vias.
  2. Inspect the KiCad-style window preview and result rows.
  3. Use Show on PCB and run visual/DRC clearance checks.
  4. Commit the exact temporary geometry, run DRC, and save.

Undo and redo

Each commit is a named native PCB group. Undo Last Commit removes the newest group and remains available after closing and reopening the plugin. Redo restores an operation undone in the current session. KiCad 10 does not expose BOARD_COMMIT to Python, so native Ctrl+Z integration is unavailable to ActionPlugins.

Limitations

This is not an autorouter or package-specific escape optimizer. It does not guarantee neck-down rules, via technology, channel capacity, return paths, or manufacturability. Run DRC and complete engineering review before fabrication.
