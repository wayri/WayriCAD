KiWay Fanout Generator

Annotated interface walkthrough

The numbered cues match the four guarded stages in the installed plugin.

Creates conservative radial, BGA/LGA-grid, or perimeter escape tracks from SMD pads.

Nothing reaches the PCB during Preview in Window. Show on PCB creates temporary selected geometry. Commit to PCB is the only action that keeps it.

Four-stage workflow

StageActionPCB effect
1. ConfigureChoose footprint, pattern, dimensions, layer, and optional vias.None
2. Window previewInspect the geometry canvas and accepted rows.None
3. PCB previewShow the reviewed geometry on the PCB and inspect it against existing copper.Temporary until cleared or closed
4. CommitCommit, run DRC, and save.Geometry remains

Undo and redo

Undo Last Commit removes every track and via from one fanout commit. Redo Last Commit restores that complete operation. KiCad 10 does not expose native BOARD_COMMIT to Python, so modeless commits use the plugin's bulk Undo/Redo controls.

Guardrails

  • Use a specific footprint reference for sensitive areas.
  • Clear Preview removes only temporary geometry.
  • This is an escape-pattern starter, not an autorouter. DRC and routing review remain required.
