KiWay Fanout Generator

Creates conservative radial tracks from SMD pads while preserving the pad layer and net code.

Use

  1. Open the target PCB and launch the tool.
  2. Enter one footprint reference, or leave it blank to process all SMD footprints.
  3. Set track width and fanout length in millimetres.
  4. Click Preview, then Generate.

Common issues

  • Too many tracks: specify a footprint reference instead of processing the whole board.
  • Clearance violations: reduce fanout length or width, then run DRC.
  • Wrong escape direction: move the footprint or route manually after generation; this tool creates a starting pattern, not a complete autorouter.

Always run DRC before manufacturing.
