# KiWay Harness and Cable Workbench 0.1.0

Imports connector pin CSV documents from two projects and generates a reviewable wire list. Matching supports exact names, wildcards with captured portions, and regular expressions. The validator reports unmatched or ambiguous signals, multiple wires at one destination, and explicit voltage mismatches.

Wire gauge, shielding, twist, current capacity, derating, insulation, creepage, connector ratings, and regulatory requirements remain engineering inputs and must be independently reviewed.
