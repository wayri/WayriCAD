Harness and Cable Workbench

Workflow

  1. Export connector pin CSV files from KiWay Pin Extractor.
  2. Import source and destination documents.
  3. Use * wildcards, or enable regex and provide a capture group.
  4. Review every ambiguous, unmatched, duplicate, or voltage-conflict row.
  5. Export the reviewed wire list.

Example

Source DEMO_CTRL_* and destination DEMO_IO_* link records by the captured suffix.

Limitations

Automatic name matching does not establish electrical compatibility. Verify pin type, voltage, current, gauge, shielding, twist, insulation, connector rating, and mating orientation.
