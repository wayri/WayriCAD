KiWay Harness and Cable Workbench 0.2.0

Build a reviewed system harness from board pin exports and endpoint loads. The workbench reads project data only and never modifies the PCB.

1. Import sources

Import multiple CSV files or scan a directory recursively. A project set may contain up to 50 unique project names.

ColumnPurpose
projectUnique board or endpoint group name.
connector / referenceConnector reference such as J1. Required.
pin / padConnector pin identity. Required.
net / net nameSignal name used by indexed matching.
function, voltageDocumentation and voltage-conflict checks.
connector part, contact partParts used by the harness BoM.
load AEndpoint current shown in the net map.

2. Define links

Indexed matching groups equal net names across different connectors and projects. Use a wildcard or regex to restrict candidates. Power nets are excluded by default to prevent accidental cross-products.

DEMO_CTRL:J1 -> DEMO_IO:J2
DEMO_IO:J4 -> LOADS:P1 [offset=1]
DEMO_A:J3 -> DEMO_B:J7 [map=1:3,2:4]

The first rule maps N to N. Offset changes numeric destination pins. An explicit map overrides listed pins.

4. Review construction

Sort tables by clicking a header. Select wires, then apply AWG, color, bundle, splice, length, and shielding. With no selection, the action applies to every link. Review unmatched, ambiguous, duplicate-destination, and voltage-conflict findings.

5. Draft and outputs

The Draft Canvas shows each connector once. Mouse wheel zooms, drag pans, and double-click inspects a connector. Export pin map, net map, wire list, procurement BoM, or universal SVG. The UI displays at most 10,000 rows; exports contain every generated row.

Troubleshooting

  • No links: confirm project/connector spelling, net pattern, and CSV columns.
  • Too many links: disable indexed matching for straight-through cables or narrow the pattern. Automatic generation stops at 50,000 links.
  • Unmatched pins: inspect connector population and use offset or explicit maps.
  • Missing BoM parts: provide connector/contact part columns. Unknown parts remain TBD.

Engineering limitation: correspondence does not prove polarity, pin gender, mating orientation, electrical compatibility, ampacity, temperature derating, insulation, creepage, shielding, bend radius, regulatory compliance, manufacturability, or testability. Verify these before release.
