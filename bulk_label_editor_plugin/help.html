KiWay Bulk Label Editor

Preview and apply repeated reference, value, field, and PCB text changes.

Use

  1. Open a PCB and launch the plugin.
  2. Enter a wildcard rule such as CH*_MAIN and replacement CH*_REDUNDANT.
  3. Select the fields to edit, click Preview, inspect every change, then click Apply.
  4. Enable Regex for regular-expression replacement and save the board.

Examples

CH*_MAIN to CH*_REDUNDANT preserves the captured channel text. Regex mode can use patterns such as ^J(\d+)_MAIN$ with replacement J$1_REDUNDANT.

Common issues

  • No matches: enable the correct scope and check case sensitivity.
  • Schematic labels unchanged: this ActionPlugin edits PCB-exposed objects; schematic label writing requires the schematic editor.
  • Unexpected replacement: always use Preview and save a board backup before Apply.
