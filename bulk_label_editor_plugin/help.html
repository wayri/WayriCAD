KiWay Bulk Label Editor

Preview and apply repeated edits to footprint references, values, fields, and PCB text. The editor changes PCB-exposed data only; it does not write schematic labels.

Cross-selection: double-click a Preview row, or use Select on PCB, to locate the owning footprint or drawing in PCB Editor before applying the edit.

Safe Rename Workflow

Wildcard and Regex

ModeFindReplaceResult
WildcardCH*_MAINCH*_REDUNDANTPreserves the captured channel text.
Regex^J(\d+)_MAIN$J$1_REDUNDANTUses the first capture group in the replacement.
  1. Choose the object scopes: References, Values, Fields, and/or PCB text.
  2. Enter a rule and click Preview. Check every proposed row.
  3. Use cross-selection for unfamiliar rows, then click Apply. Undo/Redo affects the current session.
  4. Save the board and run DRC when reference/value changes affect assembly output.

Troubleshooting

  • No matches: enable the matching scope and check case sensitivity.
  • Unexpected replacement: undo immediately, correct the rule, and preview again.
  • Schematic labels unchanged: update these in Schematic Editor; this plugin is PCB-only.
