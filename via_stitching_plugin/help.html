KiWay Via Stitching

Creates a configurable via grid and can assign every generated via to a selected PCB net.

Use

  1. Open the PCB and launch the tool.
  2. Select a net from Net to stitch, or select <No net>.
  3. Set spacing, edge inset, drill, and diameter.
  4. Keep the exclusion checkboxes enabled to skip parts, tracks, zones, and board drawings. Add references such as J1,U3 when needed.
  5. Preview, then Generate and run DRC.

Common issues

  • No net listed: save the board and confirm that at least one pad uses the net.
  • Very few vias: exclusions may cover most of the board; disable one exclusion at a time to diagnose.
  • DRC errors: increase spacing or edge inset and verify copper-zone and keepout rules.
