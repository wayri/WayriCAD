KiWay Via Stitching

Creates a configurable same-net via grid inside full-board or PCB-selection bounds.

Annotated interface walkthrough

Nothing reaches the PCB during Preview in Window. Show on PCB creates temporary selected vias. Commit to PCB is the only action that keeps them.

Area and exclusions

Use full board bounds or select footprints, pads, tracks, zones, or drawings and choose selection bounds. Auto-refresh follows selected net-bearing items. Only inside target-net copper zone uses KiCad's filled-area hit test; refill zones first. Target-net copper is allowed while unrelated tracks, vias, zones, footprints, and keepouts can be excluded.

Workflow

  1. Select a real net, spacing, inset, drill, diameter, bounds, and exclusions.
  2. Preview accepted positions and inspect rejection counts.
  3. Show temporary vias on PCB and run DRC/clearance review.
  4. Commit the exact preview, refill zones, run DRC, and save.

Undo and redo

Commits are named native PCB groups, so Undo Last Commit remains available after closing and reopening. Redo is session-local. KiCad 10 does not expose native BOARD_COMMIT to Python ActionPlugins.

Troubleshooting

SymptomResolution
No candidatesRefill zones, confirm the target net has filled copper, inspect rejection counts, and disable exclusions one at a time.
Bounds unavailableSelect an object with a bounding box in PCB Editor or use full-board mode.
DRC errorsIncrease spacing/inset or via clearances and inspect temporary PCB geometry.

Limitations

Geometric checks do not replace DRC or calculate RF fence spacing, return-current benefit, thermal behavior, resonances, or fabrication aspect ratio.
