KiWay Via Stitching

Annotated interface walkthrough

The numbered cues match the four guarded stages in the plugin.

Creates a configurable via grid for a selected net or no-net stitching pattern.

Nothing reaches the PCB during Preview in Window. Show on PCB creates temporary selected vias. Commit to PCB is the only action that keeps them.

Four-stage workflow

StageActionPCB effect
1. ConfigureChoose net, spacing, inset, drill, diameter, bounds, and exclusions.None
2. Window previewClick Preview in Window and inspect accepted positions and rows.None
3. PCB previewClick Show on PCB; inspect selected temporary vias against copper and keepouts.Temporary until cleared or the dialog closes
4. CommitClick Commit to PCB, run DRC, and save.Vias remain on the board

Undo and redo

Undo Last Commit removes every via from one stitching commit. Redo Last Commit restores the complete operation. When the dialog closes, the final plugin result is returned to KiCad as one action-plugin board change so the normal PCB Editor undo/redo chain remains available.

Troubleshooting

  • Very few vias: exclusions may cover most of the target region; disable one at a time to diagnose.
  • DRC errors: increase spacing or inset and check keepouts and zone clearances.
  • No net: save the board and confirm a pad is assigned to the target net.
