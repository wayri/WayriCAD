Trace Refiner

Preview small track-jog cleanup, validate with native KiCad DRC, then Apply.

  1. Refill zones and save the PCB and project rules. Open Trace Refiner in the originating PCB Editor.
  2. Choose selected tracks, selected nets, whole board, checked net filters or native net classes. Checked layers restrict every scope; none means all layers.
  3. Set displacement and shortening bounds in mm. Add all tuned or critical nets to Protected nets.
  4. Preview. Amber is original routing; teal is the proposed replacement. Wheel zooms; dragging pans; double-click fits.
  5. Validate candidate. Native terminal connectivity must stay unchanged and native DRC must introduce no new findings. A chain with baseline DRC findings blocks the batch. Baselines with 199 or more findings of one type are blocked because potentially capped reports cannot prove a reliable comparison. Resolve those findings first. Validation runs in a cancellable native Python process with a six-minute timeout. Core copper checks are enabled in disposable copies even when disabled in saved settings; the source project stays unchanged. Cancellation does not edit the PCB.
  6. Apply refinement. Inspect the result, refill zones and run final DRC before saving. Undo/Redo is available while this window remains open.

Protected routing

Endpoints, contacts, branches, widths and layers are retained. Locked/grouped tracks, arcs, vias, repeated tuning and native differential-pair names stay untouched. Initial wildcards protect common critical net names, but cannot infer all intent. Custom length/skew/pair rules block this first version. No shove routing, pair retuning or clearance relaxation is performed.

Limits

Bounded local cleanup can leave valid but complex routing unchanged. Centreline similarity does not prove electrical timing, impedance or reference continuity. Native DRC is a separate gate. Unsaved rule changes are not part of the saved-rule context: save Board Setup before validation. Changed board geometry, selection or saved rules invalidate operations. Closing the window discards its Undo history; ordinary PCB Editor Undo is not claimed.
