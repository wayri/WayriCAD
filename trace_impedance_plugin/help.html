KiWay Trace RLC / Impedance Analyzer

Annotated interface walkthrough

The numbered cues below match the visible workflow in the plugin. A preview is the review evidence; committing or exporting is the final step.

Measures routed-net geometry and provides first-order RLC, impedance, delay, layer, via, and zone estimates.

Cross-selection: choose a net and click Select Net on PCB to select all pads on that net before inspecting the measured route.

Workflow

  1. Select the routed net and optional start/end pads.
  2. Choose frequency and reference layer from the detected stackup.
  3. Click Analyze Path, inspect notes and metrics, then export CSV.
  4. Use PCB cross-selection to verify the intended endpoints.
MetricMeaning
Length / vias / layer changesGeometry measured from the routed board path.
RLC, impedance, delayFirst-order estimates derived from geometry and stackup metadata.
ZonesSame-net copper-zone context detected along the route.

Limit: this is not a 2D/3D field solver. Validate critical high-speed or impedance-controlled interfaces with a field solver, TDR, or measurement.
