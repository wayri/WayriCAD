KiWay Trace RLC / Impedance Analyzer

Select a routed net and optional start/end pads to inspect trace length, track layers, vias, same-net copper zones, and first-order RLC/impedance estimates.

Use

  1. Select a net.
  2. Select start and end pads when a specific path matters.
  3. Choose a reference layer and frequency, then click Analyze Path.
  4. Review notes and export CSV.

Interpretation

Results are geometry-based engineering estimates, not a 2D/3D field-solver result. Differential mate selection is provided for comparison; validate critical high-speed interfaces with a field solver, TDR, or measurement.

Common issues

  • No path: save the PCB, verify the pad net names, and select pads actually connected by tracks.
  • Unexpected length: the fallback aggregate-net estimate is used when a connected start/end route cannot be resolved.
  • Unexpected impedance: verify stackup dielectric height, copper thickness, reference layer, plane continuity, and zone geometry.
  • Missing networkx: install networkx in KiCad's Python environment for graph traversal.
