# WayriCAD 4.0.2

This release refreshes the READMEs and packages the current analysis tools.

- Short quick-start tables for Quick PI, Quick SI, QuickTherm and Quick EMerge.
- Current download links and clearer navigation in the main README.
- EMerge instructions for saved-board antenna regions, fields, 2D radiation
  cuts, interactive 3D patterns and report exports.
- Existing screenshots remain with their original capture context.

The calculation and solver behavior carries forward from 4.0.1. EMerge remains
an exploratory beta; its radiation plots show relative field, not gain or
efficiency. Existing validation records retain their original scope and dates.
