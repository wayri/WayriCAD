# WayriCAD 3.2.1 — Privacy-cleaned documentation and previews

This maintenance release keeps the 16-plugin suite and its analysis engines while replacing developer-machine paths in documentation and screenshot examples with generic project locations. It includes the current capability/limitation lists and expanded Quick PI series-element/CLI guide.

- Screenshot redactions preserve the surrounding interface and numerical results.
- Repository history is rewritten to remove the identified path text and affected historical screenshot content. Older release downloads are retired; use this release or the current PCM feed.
- Existing clones may retain the old history. Clone the updated repository afresh before contributing; avoid merging or pushing old branches that reintroduce it.
- Published source history cleanup cannot erase independent clones, forks or cached copies held by third parties.
