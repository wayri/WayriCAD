Automatic layer-change routing

A step-by-step guide to setting a protocol's track width and differential-pair gap by copper layer, applying the reviewed profile, and routing with the profile after Constraint Studio closes.

What changes automatically?

After you apply the profile and reopen the project, KiCad chooses the saved width and pair gap for a new route started on each configured layer. Constraint Studio does not have to stay open.

Save board→Set profile→Stage + export→Apply + reopen→Route
At a via: KiCad 10 keeps one width during an active route. Finish the route at the transition via and start a new route on the destination layer. Turn Auto track width off so KiCad does not inherit the width of the segment you started from.

Example numbers in the screenshots are illustrative. Set widths, gaps, clearances, references and via sizes for your actual board and fabricator.

1

Save the board and its physical stackup

  1. Open the project in KiCad PCB Editor. In Board Setup, verify the enabled copper layers, dielectric thicknesses and copper thicknesses.
  2. Save Board Setup and the PCB. Confirm the nets you intend to route are in the saved board.
  3. Open Tools → External Plugins → WayriCAD Constraint Studio. If the board was saved while Studio was open, return to the clean Studio window or use Reload saved board. Export or undo staged edits before reloading.
Check: The Physical stackup column shows the layers you expect. A missing net usually means the saved snapshot needs a reload or the net has not been placed on the PCB yet.
2

Create a profile for each protocol instance

  1. Select Layer routing profiles in the left sidebar, then New profile or + New protocol (label varies by build).
  2. Name the specific bus, for example CAN1. Choose its protocol family and Signal type: single-ended or differential.
  3. Under Apply to, choose Selected nets / group or an existing netclass. Search the saved-board net list and tick the exact members. For a pair, select both members, such as CAN_P and CAN_N. The family label alone does not create a KiCad differential pair.
  4. Use a separate tab for CAN2, an Ethernet port, DDR data, address or clock groups when they need different geometry. Duplicate copies geometry but clears net membership.
3

Enter geometry for every permitted layer

  1. Click + Signal layer for each copper layer the group may use. Select the actual signal layer and its reference plane; for an internal stripline, provide the relevant upper and lower references where applicable.
  2. Enter Width mm and, for differential routing, Pair gap mm for each row. The gap is edge-to-edge between pair traces. Use verified stackup or fabricator values. Estimate width is only a screening approximation with a fixed gap.
  3. Compare the side-by-side Layer previews. Select Trace, Pair or Trace + pair mode if available. The copper shapes should visibly change as you edit widths and gaps.
  4. Choose whether to Prohibit tracks on unconfigured layers. This is useful when every allowed signal layer has a row; it does not ban vias.

Reference-plane check: A named copper layer is not proof of an unbroken return plane. Inspect plane continuity, antipads and the return path around each via.
4

Review the optional via recipe

If this bus needs a particular via, choose its type (through, microvia, blind or buried), copper diameter, drill, and a valid start/end layer span for non-through vias. Use saved sizes can copy a netclass's dimensions for review. Confirm that the stackup and Board Setup permit that via type and that manufacturing floors are met.

Studio stages scoped DRC limits for the recipe. KiCad's tuning profile does not automatically switch the router's via type. Select the needed via type in PCB Editor when placing the transition.
5

Stage, review, export and apply

  1. Click Review & stage profile. Resolve local errors such as missing nets, overlapping assignments, stale stackup or invalid dimensions.
  2. Open Review & export. Inspect Local findings, File diff and Native rules. Export the review to a new empty folder, then run native KiCad DRC on that exported snapshot.
  3. Click Open Apply Review. Before confirming its write, close every KiCad editor for the source project. Review the helper's file list; it checks source fingerprints and creates backups.
  4. Reopen the project in KiCad PCB Editor. The applied settings persist with Studio closed. If you change the stackup later, reopen Studio and restage the profile.
Check: The review shows changes to the saved project profile and generated per-layer rules. Do not assume that merely clicking Stage has changed the currently open PCB Editor.
6

Route from one layer to another

  1. In PCB Editor, use netclass/rule-driven sizing for tracks or differential pairs. Clear any explicitly chosen manual width or gap. Turn the toolbar's Auto track width option off.
  2. Start a new single-track or differential-pair route on the first configured layer. Check the width, and for a pair the gap, shown by KiCad's router against that layer's profile row.
  3. Place the appropriate transition via. Finish the active route at the via.
  4. Switch to the destination layer, start a new route from the via and check that KiCad now selects the destination layer's width and pair gap. Repeat for each transition.
  5. Save the PCB and run native DRC. Inspect both members of a differential pair and each via/return-path transition.
Example: A front-layer segment may be 0.20 mm wide with a 0.18 mm pair gap; after restarting from the via on the back layer, the new segment may be 0.30 mm wide with a 0.25 mm pair gap. These are demonstration values, not recommended dimensions.

Verify that it worked

  • Start a new route on each configured layer and inspect KiCad's displayed width or pair gap. The destination-layer value should be selected without a manual size change.
  • Save, close and reopen the project. Repeat one route-start check with Constraint Studio closed to verify persistence.
  • Inspect the saved track properties and run DRC for wrong widths, pair gaps, via dimensions and layer restrictions. Existing tracks are not resized by the new profile.
  • If using several CAN, Ethernet or DDR groups, test a net from each instance. Exact-net membership does not auto-include a newly named net.

The recorded KiCad 10.0.6 single-track check measured 0.20 mm on F.Cu and 0.30 mm on B.Cu after a route restart with Auto track width off. A user subsequently confirmed differential-pair layer routing in their session; the repository does not contain a measured route capture for that pair test.
