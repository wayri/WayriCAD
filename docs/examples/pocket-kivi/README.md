# Actual saved-PCB examples for Pocket KiView

These small public examples were generated by the existing saved-board Quick PI,
Quick SI and QuickTherm producer services on the **same included native PCB**.
They are not analytical-strip outputs assigned an unrelated board hash. The
source file SHA-256 is
`8d60e824376418fa4cad65d37c9d8c8dd5da60c5538b9bf0a11976dbb98f1e7e`.

Download or import [example.kicad_pcb](example.kicad_pcb) and its
[example.kicad_pro](example.kicad_pro) project rules alongside these results:

| Saved result | Actual retained data |
| --- | --- |
| [Quick PI](quick-pi.pocket-kivi.json) | Saved copper mesh, 180 nodes and 230 triangles; 26 unknown nodal voltages and 24 floating triangles on the disconnected copper island. |
| [Quick SI](quick-si.pocket-kivi.json) | Measured 20 mm source-to-receiver route with exact net, pad and track UUID bindings; section screening, 127 illustrative eye traces with 129 samples each, and a 555-sample step response. |
| [QuickTherm steady](quick-therm.pocket-kivi.json) | Saved two-layer physical copper and board field on a 24 × 12 grid, with 276 active cells per layer; component/source mapping and producer probes. |
| [QuickTherm transient](quick-therm-transient.pocket-kivi.json) | The same saved-board multilayer workflow with full layer-major temperature frames at 0, 0.5 and 1 seconds; 552 stored temperatures in each frame. |

The collection is approximately 0.45 MiB. Every saved sample is retained. The
root PI `mesh`/`result` shape and thermal/SI structures remain intact, and each
portable report names `example.kicad_pcb` with its exact saved-byte hash.

## Geometry and declared assumptions

The fixture is a 30 × 15 mm, two-layer board with 35 µm copper, a 1.53 mm FR4
core, relative permittivity 4.2 and loss tangent 0.02 in its saved stackup. Its
front trace is 1 mm wide from `J1.1` at (5, 5) mm to `U1.1` at (25, 5) mm.
The exact hierarchical net name is `/Front outputs/SLOT1`. A separate same-net
floating track exercises missing electrical values. A rectangular cutout spans
(12, 9) to (18, 13) mm. The saved back-plane polygon also excludes that cutout.
The polygon is explicitly authored saved copper; native zone-refill/DRC closure
has not been claimed. The fixture is an export example, not a production design.

Quick PI uses 3.3 V and a prescribed 0.25 A sink, 1 mm VTK mesh edges and the
existing fixed-temperature copper model. The saved sink voltage is
3.297783428571428 V and total copper loss is 0.000554142857142941 W. This simple
model's voltage drop matches an 18 mm conducting span between the facing pad
edges; the tests retain the producer values rather than changing the solver.

Quick SI measures the actual saved route and retains its section evidence.
Termination/eye screening explicitly assumes a **uniform 50 Ω line and effective
permittivity 3**, a 20 Ω source, open receiver, 1 ns edge, 100 MHz screening
frequency, 100 Mbit/s and 1 V source swing. Its 0.11554999209278821 ns delay
uses the measured 20 mm path and that declared permittivity. The eye is the
existing ideal uniform-line model, not measured data, a field solution, IBIS
simulation or protocol compliance evidence. Its assumptions do not replace the
separately saved section impedance/reference-coverage evidence.

QuickTherm applies an independent explicit **0.05 W** source to `U1`, with
4 K/W junction-to-board resistance, 20 °C ambient, 0.3 W/(m·K) dielectric
conductivity, 10 W/(m²·K) convection and zero emissivity. This heat input is not
silently coupled to the PI Joule loss. The saved steady board-site temperature
is 36.11237007668578 °C; the declared package estimate is 36.31237007668578 °C.
Mesh refinement and physical thermal validation were not performed.

The transient uses backward Euler with 0.25 s steps, explicit copper/dielectric
volumetric capacities of 3,450,000 and 1,700,000 J/(m³·K), and 20 °C initial
temperature. Its step schedule holds `U1` at full declared power through the
last integrated interval and turns it off at 1 s; no later cooling frame is
invented. `spatial_index.cells` lists `[xIndex, yIndex]`; node indexing is
`layerIndex * active_cells_per_layer + cellIndex`. Missing cutout cells remain
gaps. Layer coordinates are the producer's saved copper midplanes at 0.0175
and 1.5825 mm depth from the front surface.

## Provenance, regeneration and checks

[provenance.json](provenance.json) records actual producer versions, selected
producer module hashes, runtime versions, every declared request input and
output hashes. All source names are repository-relative. The examples were
generated with KiCad 10.0.6 native Python 3.11.5 and existing numerical libraries.
The native PCB parsed successfully and remained byte-for-byte unchanged through
all four producer runs. SI custody includes the included project-rule file and
the recorded absence of custom `.kicad_dru` rules. Fixture-local `.kicad_prl`
display defaults are not distributed.

From the repository root, run the generator with your existing KiCad Python:

```text
<KiCad-Python> tools/generate_pocket_kivi_examples.py --viewer-extension <Pocket-KiView>/extension
```

The generator reuses the included source PCB instead of changing it on every
run. If an output directory has no board, it creates the public fixture there.
It runs all saved-board services and exports through the shared portable helper.
It never installs a runtime, edits global editor settings, or reads a private
board. Native KiCad polygon bindings, NumPy, SciPy, VTK and Matplotlib are required;
Node.js is additionally required when requesting the viewer adapter check.

Run `python -m pytest tests/test_pocket_kivi_examples.py -q` for the stored
fixture/value/hash checks. Set `WAYRICAD_NATIVE_PYTHON` to an existing native
KiCad Python to additionally reproduce all four services in a workspace temporary
directory. Set `POCKET_KIVI_VIEWER_EXTENSION` to a local viewer extension directory
to rerun its adapters. These environment variables are optional discovery inputs,
not saved project settings. Unavailable optional checks are reported as skips.

These checks establish export round trips, exact saved-source binding and viewer
compatibility for this fixture. They do not establish solver accuracy for other
geometries, mesh convergence, DRC acceptance or live-editor compatibility.

Producer source checksums normalize only Git checkout CRLF-to-LF conversion.
Saved boards, project files and result files retain exact-byte checksums.
