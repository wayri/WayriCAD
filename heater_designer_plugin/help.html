PCB / Foil Heater Designer

Workflow

  1. Set the usable heater rectangle, copper thickness, supply, layer count, width, and spacing.
  2. Enter one zone per line as name,X%,Y%,radius%,resistance factor. A factor above 1 narrows copper and raises local series resistance; below 1 widens it.
  3. Generate the copper preview and check resistance, current, power density, widths, and transitions.
  4. Run the thermal model, adjust zones, then use Show on PCB. Commit only after clearance review.

Patterns

Serpentine and zoned raster maximize area coverage. Concentric spiral supports centrally biased structures. Multilayer mode creates a continuous series path and transition-via list.

Thermal assumptions

The solver distributes calculated trace loss into a board-plane grid and iterates lateral conduction plus uniform two-sided convection. It includes copper temperature coefficient in the report, but does not solve enclosure airflow, radiation, anisotropic laminate, adhesive interfaces, attached masses, or closed-loop control dynamics.

Safety: This is a design-review tool, not thermal or fire-safety certification. Check current density, fusing behavior, creepage, laminate Tg, maximum surface temperature, sensor placement, redundant cutoff, and single-fault behavior.

Troubleshooting

If no PCB geometry appears, generate first, choose a valid origin, then click Show on PCB. Clear the temporary preview before changing geometry. Run KiCad DRC after commit.
