WayriCAD Visual Diff

Save the board or root schematic, then choose it in the local launcher. The design must belong to a Git repository.

  1. Choose Compare revisions, or View one revision.
  2. Set the base and head. HEAD is the latest commit; WORKTREE includes saved local edits.
  3. Choose an HTML report destination and select Create report.

Use the report's sheet and layer list, side-by-side, overlay, swipe and changes views. Drag to pan, scroll to zoom, or fit the page or drawing. All report assets are local.

Rendering options contains comma-separated PCB layers, an installed KiCad theme, the previous filename for renamed designs, and an optional KiCad CLI path.

Requires Git and KiCad 10+ CLI. Reports do not include unsaved editor changes, DRC results or editor overlays. Raster changes are a review aid. Git LFS pointers, symlinks and submodules are unsupported. Each snapshot is limited to 250 MiB. Add .wayricad-visual-diff/ to your project's ignore file.

No online service runs when opening this plugin. KiCad 11 compatibility remains unverified.
