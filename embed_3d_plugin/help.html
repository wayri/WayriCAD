WayriCAD Embed3D

Scan, select and process saved design assets.

  1. Save the PCB or schematic, then click Scan.
  2. Check the wanted symbols, footprints and 3D model sets in the component list. Select a row to inspect its paths. A 3D checkbox includes all model files linked to that component.
  3. Click Preview embed + relink to review a new design copy with embedded, linked assets, or Preview unwind to extract selected embedded files into a unique folder under local/.
  4. Review the preview, then click Apply preview. Original saved designs are unchanged.

Search only filters visible rows; it does not clear selections. Options & library tools retains other selective actions, path settings, diagnostics, and Localize entire project with backup. The full-project workflow updates saved project files after preview and requires the editors to be closed. Missing external model files require their source folder or explicit partial mode.

KiCad 10 native Python is required for footprint normalization and validation. KiCad 11 acceptance remains unverified.
