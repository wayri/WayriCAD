Full plugin guide and command reference. This page and its illustrations are installed locally; an internet connection is not required.

Scan, select and process saved design assets.

  1. Save the PCB or schematic, then click Scan.
  2. Check the wanted symbols, footprints and 3D model sets in the component list. Select a row to inspect its paths. A 3D checkbox includes all model files linked to that component.
  3. Click Preview embed + relink to review a new design copy with embedded, linked assets, or Preview unwind to extract selected embedded files into a unique folder under local/.
  4. Review the preview, then click Apply preview. Original saved designs are unchanged.

Search only filters visible rows; it does not clear selections. Options & library tools retains other selective actions, path settings, diagnostics, and Localize entire project with backup. The full-project workflow updates saved project files after preview and requires the editors to be closed. Missing external model files require their source folder or explicit partial mode.

KiCad 10 native Python is required for footprint normalization and validation. KiCad 11 acceptance remains unverified.

What each operation writes

OperationResult and review boundary
ScanRead-only inventory of saved component assets and resolved paths.
Preview embed + relinkProposes a new saved design copy containing the checked assets. Review before Apply preview.
Preview unwindExtracts checked embedded assets to a unique local folder after Apply. It does not rewrite the source design.
Localize entire project with backupUpdates saved project links and local libraries after a separate preview. Save and close project editors first.

Resolve model paths

Inspect the path for a selected component. Supply additional model roots when a relative or environment-variable path cannot be resolved. Explicit NAME=FOLDER variables must point to actual local folders. A checked 3D box includes all linked models on that component, not just the first one. Missing source files cannot be reconstructed.

Command-line dry run and recovery

wayricad-library localize-project board.kicad_pcb
wayricad-library localize-project board.kicad_pcb --library-folder libraries/local --apply
wayricad-library restore-local PROJECT/.wayricad-backups/BACKUP --apply

The first command previews only. Review unresolved assets before using --apply; partial mode is explicit and an unresolved-assets exit status is not a complete localization. Backups include hashes and restore protects later edits.

Troubleshooting

  • Empty scan: save the correct root schematic/PCB and scan again; unsaved editor content is not the input.
  • Unresolved models: add the original model folder or correct its variable mapping. Use partial mode only when retained external references are acceptable.
  • Source changed or destination conflicts: stop, review the changed files and run a fresh scan/preview. Do not delete unrelated local library assets.
  • Normalization unavailable: select the installed KiCad 10 native Python through WAYRICAD_KICAD_PYTHON. Pure-Python tests do not establish native acceptance.

The localization scope does not collect arbitrary datasheets, SPICE models or unrelated top-level schematics. Keep those project resources separately.
