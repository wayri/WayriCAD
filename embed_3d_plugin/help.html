WayriCAD Embed3D

Package the assets a project needs into a reviewed project copy.

  1. Save the project in KiCad, then scan it.
  2. Select components and independently choose symbols, footprints and models.
  3. Review missing assets, proposed changes and the destination.
  4. Apply to a new folder, open that copy in KiCad and verify its libraries and 3D view.

The IPC launch supports saved files and existing footprint archives. Native footprint normalization requires the KiCad 10 native bridge and is disabled in IPC mode.

Use the recovery tools and manifests to inspect or restore an operation. The source project is preserved. For command-line options, run python -m embed_3d_plugin --help.
