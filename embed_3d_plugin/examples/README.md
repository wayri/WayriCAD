# Disposable example

`input.pretty/EmbedDemo.kicad_mod` links `../models/sample_box.wrl` and has non-default scale, rotation and offsets.

`portable.pretty/EmbedDemo.kicad_mod` was generated by the supplied core embedding engine. Its embedded payload was decoded and matched byte-for-byte against the original model. It no longer needs the `models` directory for that model reference. This is a format/payload example, not a claim that native KiCad rendering was tested here.

Add each .pretty folder to a disposable KiCad 10 project under distinct library nicknames. Compare their 3D settings and rendering. Then copy only the portable `.kicad_mod` into a fresh `.pretty` folder elsewhere and load it without the original model directory.

Recorded settings for both footprints:

- Offset (mm): X = -0.25, Y = 0.5, Z = 0.8.
- Scale: X = 1.25, Y = 0.8, Z = 1.5.
- Rotation (degrees): X = 15, Y = 20, Z = 35.

The VRML box is original demo geometry licensed under the package's MIT license. KiCad's VRML unit handling is separate from this embedding test; neither the model bytes nor the scale values are converted by the plugin.
