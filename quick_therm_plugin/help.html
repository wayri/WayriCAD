WayriCAD QuickTherm

Open a saved PCB, map the footprint fields containing dissipated power and thermal resistance, select the components to analyze, then run the steady-state screen. Review the coverage and assumptions before interpreting temperatures.

First run

  1. Set Power_W and an air RthetaJA field, or use your own exact field names. Map optional minimum and maximum junction-temperature fields.
  2. Select the dissipating components and choose air or vacuum.
  3. Run, inspect top/bottom views, sort the component table and review PASS/FAIL/UNKNOWN limits.
  4. Expand the board view and click Place probe for virtual temperature probes. Export local HTML/JSON evidence.

Airflow, board conduction, heatsinks and fixed-temperature boundaries are optional models requiring explicit assumptions. This is a screening tool, not CFD or a transient solver.

The full step-by-step guide is included locally.
