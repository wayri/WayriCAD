WayriCAD QuickTherm

Open a saved PCB, select the dissipating components, and enter explicit power and thermal resistance for each one with Enter component inputs…. No custom PCB fields are required, and the board is not changed. If the saved footprints already contain complete thermal values, choose Use saved footprint fields instead. Review the coverage and assumptions before interpreting temperatures.

First run

  1. Select the dissipating components and choose air or vacuum. Review the visible ambient temperature.
  2. Enter each selected part's power in W and RθJA (air), RθJB (vacuum), or RθJC (virtual heatsink) in K/W. Blank values are never guessed. Vacuum also needs an explicit board-to-environment path for parts without heatsinks.
  3. Run, inspect top/bottom views and the sortable component table, and review PASS/FAIL/UNKNOWN limits.
  4. Expand the board view and click Place probe for virtual temperature probes. Export local HTML/JSON evidence with input provenance.

Optional CalculiX 3D board conduction

Under the board-model controls select CalculiX 3D · fixed lower face, use Locate CalculiX… to select ccx, then Check solver setup. Save the board, select top-side power sources, and enter or map their dissipated power. The model needs a fixed lower-face temperature and explicit material and mesh values. RθJB is optional; without it the board field can be solved, but package junction temperature and junction-limit checks remain unknown. Gmsh may need a first-time install in the private runtime. Vias, mounting contacts, heatsinks, convection and radiation are outside this mode.

Airflow, board conduction, heatsinks and fixed-temperature boundaries are optional models requiring explicit assumptions. This is a screening tool, not CFD or a transient solver.
