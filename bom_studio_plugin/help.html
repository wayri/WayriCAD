WayriCAD BOM Studio

Version 3.1.0 · Local desktop interface · KiCad 10+

Prepare a BOM

  1. Open a KiCad project or the root schematic.
  2. Choose BOM settings to reorder fields, edit headings, show or hide columns, group matching components, sort, filter DNP parts and set CSV formatting.
  3. Save the workspace. Changes are kept in the project’s .wayricad-bom.json sidecar and support Undo.
  4. Export using the native KiCad engine or an explicitly selected custom workspace template.

Find tools

The five main views are BOM workspace, Variants, Exports & templates, Review & native sync, and Compatibility & help. Expand More tools for catalogues, sourcing, checks, analytics and automation.

Saved sources and workspace edits

Native exports read the saved KiCad files and use the selected BOM settings. Staged component edits are not included automatically. Use Review & native sync to review and apply backed-up source changes, or export staged data with a custom workspace template.

Installation and command line

Install the PCM ZIP intact through KiCad’s Plugin and Content Manager. The package requires wxPython and the KiCad IPC Python client. Windows also requires WebView2; Linux requires wxGTK WebKit support. If the embedded runtime is unavailable, the same local interface opens in your installed browser. Use Quit to stop its local service. All interface files are bundled locally.

Try python cli.py gui --demo or python cli.py --help. Native settings can be changed using bom-format configure PROJECT --config settings.json.

KiCad 11 uses capability checks; live acceptance is not claimed. See README for details.
