## Changes and distribution

WayriCAD rasterized those sources with Inkscape to transparent RGBA PNGs at 16, 24, 32, 48, 64, 96 and 128 pixels and renamed the output files. The 64-pixel light image is also the PCM package image. No design changes were made. The rasterizations remain CC-BY-SA-4.0; retain this attribution, the license link and a notice of further changes when redistributing or adapting them.

`plugin.json` supplies separate light and dark PNG arrays at 24, 48 and 96 pixels for toolbar high-DPI selection. Original code and synthetic examples remain MIT-licensed; this artwork is an explicit exception to that code license. No font files are included.
