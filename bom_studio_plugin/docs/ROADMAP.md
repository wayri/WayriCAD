# Post-0.6 roadmap and acceptance boundaries

The local catalog, scoped review controls, declared land-pattern comparator, multi-build simulator, mass suggestions and bounded DOM viewport are implemented. They are not substitutes for the unexecuted acceptance work.

**Next release blockers:** real KiCad 10 host matrix across OS/interpreters; native symbol/footprint library loading; real PCB/schematic selection relay and viewport focus; native job-set output collection; representative production-project parsing/reload. The supplied hosttest recorder leaves absent/manual work unexecuted.

**Qualification depth:** interactive graphical land-pattern transcription, manufacturer-specific pin-function/land-pattern evidence ingestion, courtyard/paste/3D/process tolerances, electrical/thermal qualification and differentiated source credibility. Current comparator is bounded and manual-source-driven.

**Controlled collaboration:** enterprise identity/SSO, public-key/hardware-backed signatures, signed output manifests, multi-user review/approval segregation and policy administration. Current local HMAC accounts explicitly trust the OS/database owner.

**Supply-chain depth:** reviewed split-allocation optimization with currencies/taxes/freight, transactional inventory reservation/ERP, automatic validated pricing tier feeds and lifecycle PCN providers. Current scenarios consume dated entered pools in memory and do not order/reserve.

**Scale/accessibility:** streaming source/resolution backend, virtualized expanded groups and very large reports, sustained production datasets, progress/cancel across every long computation and actual assistive screen-reader/WCAG acceptance. Current published benchmarks cover only the measured SQLite and browser-DOM scenarios.

**Native evolution:** stable direct schematic adapter and fully executed KiCad 11 compatibility. Unknown formats/APIs remain gated; future support is not inferred from a major-version name.
