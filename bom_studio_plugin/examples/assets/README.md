# Synthetic asset inspection examples

SYNTHETIC_resistor.wrl and SYNTHETIC_resistor.step are original, deliberately simplified three-solid resistor-like demonstration geometry authored for WayriCAD v0.7. They are not manufacturer specifications, footprints, mass evidence, purchasing recommendations or qualified production parts. MIT, like the package. No external textures, fonts or geometry files are required. The engineering-demo launcher copies them to a temporary project, associates both models with a two-pad demonstration footprint (STEP initially hidden), then harvests them into a temporary catalogue.

The native source files remain separate from derived preview meshes. After reviewing the examples, test actual project copies on your own KiCad installation.
