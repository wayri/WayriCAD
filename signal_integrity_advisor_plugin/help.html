Interpret the numbers

QuantityDefinition / caution
DelayComplete modeled delay, or length × sqrt(effective Er) / c under an explicit assumption. Partial RLC delay is not used as a complete total.
Electrical length360 × frequency × delay. Frequency is not assumed to be the data rate.
Edge screeningRequest transmission-line review when delay is at least one sixth of the entered rise time. A short-path result is not signoff.
Reflection Γ(R − Z0) / (R + Z0), ideal resistive endpoint model. Open load +1, short −1.
First arrivalZ0 / (Rsource + Z0) × (1 + Γload). First lossless load step, not peak overshoot or an eye diagram.
Series candidateZ0 − Rsource when nonnegative. Review topology and device limits before choosing termination.

Vias, reference transitions, multi-terminal branches and zone corridors require further review. Reports list structured blocker codes and the next action for each missing input or unsupported model.

Illustrative eye and step response

Expand Illustrative eye (optional), enable the model, enter the NRZ bit rate and open-circuit source swing, then screen the path. The Eye / step tab and exported HTML show the receiver PRBS7 eye and step response.

This capture uses the same Marble path with assumed 50 ohm Z0, effective Er 3.2, a 100 ps rise time, 1 Gbps bit rate, 1 V open-circuit source swing, 20 ohm source and open receiver. It is not a USB compliance result.

The model uses a uniform lossless line, resistive endpoints and equal linear rise/fall ramps; rise time is 10–90%. Periodic PRBS7 includes settled history. The ideal clock is aligned to first arrival. Center opening is minimum high minus maximum low at 0.5 UI, not optimized eye height. Negative opening indicates overlap at that phase. The 64 samples/UI can miss narrow peaks.

No IBIS nonlinear drivers, receiver capacitance, coupling, via discontinuities, noise, jitter, clock recovery, eye masks or BER are simulated. Vias can contribute to route delay estimates but their discontinuities are not modeled. Unknown delay/Z0, zones and extra terminals make a routed eye unavailable. Excessive or non-decaying reflections produce an error.

wayricad-si eye --z0-ohm 50 --delay-ns 0.4 --source-ohm 20 --rise-ns 0.1 --bitrate-mbps 1000 --swing-v 1 --html eye.html --output eye.json

The standalone eye command needs ordinary Python only. For a board path add --eye-bitrate-mbps 1000 --eye-swing-v 1 to screen. An explicitly requested unavailable routed eye returns exit code 3. Source matching can be compared by changing resistance and rerunning; input changes clear old plots.

Model basis: TI AN-807: Reflections—Computations and Waveforms. Successive receiver arrivals follow the product of the source and load reflection coefficients; the report preserves all assumptions.

Troubleshooting and limits

For unresolved routing check exact pad labels, physical continuity and filled zones. For unknown line estimates check continuous adjacent return-plane coverage and the saved Board Setup stackup. Automatic Z0 requires physical dielectric thickness and Er; missing values remain unknown and are never replaced by generic FR-4 dimensions. Follow the report's blocker actions rather than entering a number merely to obtain a result. A saved snapshot needs save/refill and reopen after board changes. Changing a form input clears its prior report.

No full-wave, IBIS-based eye, crosstalk, receiver-capacitance or coupled-line simulation is claimed. Zone corridors are not full plane solutions; effective Er differs from bulk laminate Er. The tool never edits copper.

Protocol suites: low-speed buses through high-speed serial interfaces

Choose among 33 profiles for I2C, SPI, UART, CAN, I2S/TDM, parallel GPIO, SDIO, USB, LVDS, SerDes, PCI/PCIe, DDR, Ethernet and M.2 PCIe/SATA. M.2 alone does not identify an electrical interface. Profile rates and nominal targets are reference information, not compliance limits.

  1. Screen a connected path in Quick SI using actual driver inputs.
  2. Open Protocol suites, choose the interface and Add current Quick SI path. Add each independent route.
  3. Assign P/N roles to a pair or clock/data to a bus, with the same group name. DDR DQ groups use the relevant strobe as clock; coupled strobe behavior remains unmodeled.
  4. Expand Optional engineering budgets for maximum delay (ns), skew (ps), single-ended target deviation (%) or delay/rise ratio. Blank budgets stay unknown.
  5. Run the suite. Inspect checks, selected route and optional eye/step; export local HTML or JSON. Changed assignments/budgets clear the result.

WITHIN_BUDGET applies only to evaluated quantities. REVIEW marks exceeded budgets or mismatched illustrative eye rate. Independent single-ended routes cannot establish differential impedance, crosstalk or protocol certification.

Differential pair delay and phase matching

In Protocol suites, add P and N route snapshots with the same Group. Run the suite and open Pair delay / phase. Both leg delays, signed N-minus-P skew and pair mean-delay differences are shown. Select a row for full model evidence and its first route in Selected route.

Enter an explicit Pair phase frequency (MHz) for phase; leave blank for delay/skew only. Reference pair group is optional and defaults to the first valid pair alphabetically. HTML includes the complete static pair table, even without JavaScript. Changes clear stale results.

Skew = tN - tP; phase mismatch = -360 f (tN - tP), with seconds and Hz. Positive skew means N arrives later. The intended 180-degree differential inversion is excluded. Mean pair delay is (tP + tN)/2; lane skew compares that mean to the reference pair. 125 ps skew at 1 GHz means -45 degrees. Wrapped phase uses [-180, 180).

wayricad-si suite --profile lvds --reports p.json n.json --timing-frequency-mhz 100 --html pair-timing.html --output pair-timing.json

Each report needs explicit P/N role, pair group, distinct routed nets, resolved delay/model provenance and matching saved board fingerprints. The CLI compares recorded revisions and does not reopen boards. Check transmitter-to-receiver direction. Missing evidence remains unknown. These independent route estimates are not a coupled differential or dispersive phase solution; package/device/launch/via discontinuity delays and common-mode conversion are not solved. No phase/skew standard is inferred. For a pure delay, H(f) = exp(-j 2 pi f t), which gives the stated propagation phase; this does not establish channel bandwidth.

IBIS transient timing advice

In circuit export, Suggest timing from selected routes proposes the smallest rise/20, delay/20 and period/100 timestep, and a duration covering ten slowest periods, eight longest delays and ten slowest rises. Every chosen route needs a positive resolved delay, declared rise time and frequency. The two-million duration/step ratio is enforced without silently coarsening. Adaptive internal steps may be smaller and more numerous. Actual IBIS bandwidth and timestep convergence still need review. Both schematic and clipboard use .tran TSTEP TSTOP 0 TMAX, with the reviewed timestep explicitly setting TMAX. This bounds adaptive internal steps; it does not guarantee uniform output samples or convergence. See the official ngspice .TRAN definition. Manual via approximations remain off unless you explicitly enable them.

Endpoint shunt capacitors in transient circuits

In Export KiCad circuit or Copy circuit, open Shunt capacitors…. Enter a case, unique capacitor ID, source/receiver attachment, C in nF, ESR in mΩ and ESL in nH. Each capacitor remains an individual series ESR/ESL/C branch to ideal common ground. Blank C is an error; zero ESR/ESL omits that element.

Native demonstration editor, entered receiver 100 pF/50 mΩ/1 nH and source 1 nF/20 mΩ/0.8 nH. No board was opened or changed; this is not a solved waveform.

Route timing advice does not include capacitor/ESL timescales; a warning remains in the export settings. The built-in illustrative eye and resistive endpoint screen do not include these branches.

HTML and PDF reports

Export HTML for interactive board views and exact probes. Use Print / save as PDF for browser printing. For a static PDF without a browser, run python -m wayricad_runtime.tool_cli report-pdf review.html --output review.pdf --evidence review.json after installing wayricad[reports]. The exporter retains text, tables and embedded PNG/JPEG figures. Canvas, SVG and unsupported views are explicitly listed as retained in HTML. Any tool JSON can use python -m wayricad_runtime.tool_cli report result.json --html review.html --pdf review.pdf; no analysis is recomputed.

Blender visualization

This feature is in the updated source; existing 3.6.40 installers do not contain it.

After a supported result, choose Blender…. Select a new export folder and optionally open an installed Blender. Export runs in a worker. Geometry and available result fields are preserved; animation uses stored computed samples. A static SI/DC result does not become a traveling-wave or transient simulation. Simplified component envelopes are not STEP solids. Full Blender workflow and limits.
