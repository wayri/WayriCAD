WayriCAD Quick SI

Measure a routed source-to-receiver path, screen delay and resistive termination, and export local evidence. This upgrades the existing Signal Integrity Advisor package; no second SI plugin is needed.

Neighbour trace exposure map

Open Neighbour traces, choose/type an exact target net (blank searches all connected nets), select a copper layer and radius in mm, then Map neighbours. Search results, hover/click traces or select a table row for shortest edge gap, parallel overlap and closest board location. Wheel zooms, drag pans and Fit map restores the overview.

Colour means geometric gap: red at contact, amber at half the radius, teal at the radius. It is not field intensity, interference voltage or compliance. UNKNOWN coupling stays unknown. Only straight same-layer tracks are searched; arcs, vias, pads, zones and other-layer coupling are not solved. An empty map does not establish zero interference.

Optional explicit reference/material/edge inputs reuse the existing converged ideal homogeneous-plane equal-width matched-end model. Reference continuity, terminal direction and whole-route loading remain unresolved. Link current study sections retains directed study NEXT by matching saved-source hashes and UUIDs; section extent/reference evidence stays separate and peaks are never added. Export retains searchable/selectable SVG, HTML/JSON, units, coverage and unknown reasons. Input changes clear stale maps; changed saved source requires reopening. Budgets: 200,000 tracks/comparisons, 500,000 index references, 800,000 candidate visits, 2,000 pairs, 32 local models and 15 seconds. Narrow scope when INCOMPLETE. CLI: neighbours board.kicad_pcb --net DATA --radius-mm 1 --html neighbours.html --output neighbours.json.

Start with the active project

  1. Save the board and refill zones in the originating PCB Editor. Launch Quick SI. A native loading window appears while KiCad reads a large saved board; closing it cancels opening after the current read finishes, without changing the board. A saved matching selection seeds the net and endpoints; otherwise review the proposed two-pad net.
  2. On Quick SI, choose a net and distinct source/receiver pads such as U1.1 and J1.1.
  3. Enter the driver's actual rise time and resistance. Defaults of 1 ns and 20 ohm are assumptions.
  4. Expand Line and load assumptions for frequency, resistive load, reference layer, assumed Z0 and effective Er. A blank load means ideal open circuit. Blank Z0/Er retains geometry-derived values or unknowns.
  5. Choose Screen selected path. Review the model basis, notes and route; Fit, pan and zoom as needed. Export a local HTML report to the project directory.

This Marble route is 9.612525 mm with 7 tracks and 2 vias. The screenshot assumes 50 ohm Z0, effective Er 3.2, 1 ns rise time, 20 ohm source and open load: 57.3577 ps delay and a 30 ohm series-match candidate. These are conditional screening values, not USB compliance results.

Interpret the numbers

QuantityDefinition / caution
DelayComplete modeled delay, or length × sqrt(effective Er) / c under an explicit assumption. Partial RLC delay is not used as a complete total.
Electrical length360 × frequency × delay. Frequency is not assumed to be the data rate.
Edge screeningRequest transmission-line review when delay is at least one sixth of the entered rise time. A short-path result is not signoff.
Reflection Γ(R − Z0) / (R + Z0), ideal resistive endpoint model. Open load +1, short −1.
First arrivalZ0 / (Rsource + Z0) × (1 + Γload). First lossless load step, not peak overshoot or an eye diagram.
Series candidateZ0 − Rsource when nonnegative. Review topology and device limits before choosing termination.

SCREENED is not PASS. INCOMPLETE retains unresolved line terms; UNRESOLVED has no usable endpoint path. Explicit assumptions never establish connectivity. Vias, reference transitions, multi-terminal branches and zone corridors require further review. Reports list structured blocker codes and the next action for each missing input or unsupported model.

Without explicit line assumptions, this route's unresolved total delay and uniform Z0 remain unknown.

Illustrative eye and step response

Expand Illustrative eye (optional), enable the model, enter the NRZ bit rate and open-circuit source swing, then screen the path. The Eye / step tab and exported HTML show the receiver PRBS7 eye and step response.

This capture uses the same Marble path with assumed 50 ohm Z0, effective Er 3.2, a 100 ps rise time, 1 Gbps bit rate, 1 V open-circuit source swing, 20 ohm source and open receiver. It is not a USB compliance result.

The model uses a uniform lossless line, resistive endpoints and equal linear rise/fall ramps; rise time is 10–90%. Periodic PRBS7 includes settled history. The ideal clock is aligned to first arrival. Center opening is minimum high minus maximum low at 0.5 UI, not optimized eye height. Negative opening indicates overlap at that phase. The 64 samples/UI can miss narrow peaks.

No IBIS nonlinear drivers, receiver capacitance, coupling, via discontinuities, noise, jitter, clock recovery, eye masks or BER are simulated. Vias can contribute to route delay estimates but their discontinuities are not modeled. Unknown delay/Z0, zones and extra terminals make a routed eye unavailable. Excessive or non-decaying reflections produce an error.

wayricad-si eye --z0-ohm 50 --delay-ns 0.4 --source-ohm 20 --rise-ns 0.1 --bitrate-mbps 1000 --swing-v 1 --html eye.html --output eye.json

The standalone eye command needs ordinary Python only. For a board path add --eye-bitrate-mbps 1000 --eye-swing-v 1 to screen. An explicitly requested unavailable routed eye returns exit code 3. Source matching can be compared by changing resistance and rerunning; input changes clear old plots.

Model basis: TI AN-807: Reflections—Computations and Waveforms. Successive receiver arrivals follow the product of the source and load reflection coefficients; the report preserves all assumptions.

Reviewed IBIS circuit export

The IBIS models for KiCad circuit export pane is separate from the ideal Eye / step result above. After saving and screening a route, click Load IBIS… for the source and receiver, or Use source file for receiver. Choose the exact IBIS Component, Pin, compatible Model and one typ/min/max corner for VCC and pin R/L/C. The PCB pad number is suggested only when it exactly matches an IBIS pin; choose a different pin explicitly for a reviewed package mapping. The pane displays PCB Reference.Pad → IBIS Component.Pin, and the file tooltip shows its full path. Ambiguous components or models need a choice; source/receiver direction is not inferred from IBIS.

For a multi-net study, select each completed case above the route preview and assign its source and receiver. Export KiCad circuit… and Copy circuit… let you check completed cases; a checked case with a missing assignment produces an error. Choose duration, maximum timestep, stimulus frequency and duty cycle (defaults 100 ns, 0.1 ns, 100 MHz and 50%). Copper thickness is blank by default. Via L/C is enabled only with explicit approximation consent. Choose a parent folder for a new SI-circuit-… bundle. Copy creates the same bundle first, then copies schematic text. Keep the copied models/ IBIS files and bundle; a pasted circuit references them. Open the exported project in KiCad Schematic Editor, inspect its manifest and run KiCad's native simulator. Export does not itself run the IBIS transient.

The circuit requires exactly two signal pads and whole-net evidence that every routed item belongs to one complete path. Zones, branches, stubs, loops and unresolved sections are rejected. Vias need reviewed manual capacitance and complete loop inductance with approximation consent. If saved copper thickness is missing, enter a reviewed thickness and rescreen with explicit assumed Z0 and effective permittivity before exporting. The project models independent point-to-point cases with an ideal common reference, not inter-net coupling, full-wave fields or protocol compliance. Changed board/rules files or IBIS bytes invalidate the export. Each fresh export uses distinct non-ground signal names. Pasting the same clipboard fragment repeatedly reuses its global signal names and connects those copies; re-export for an electrically isolated second copy. Ground remains common.

wayricad-si ibis-catalog C:/Projects/Example/models/driver.ibs --output driver-catalog.json
wayricad-si circuit route.json --assignments ibis-assignments.json --output C:/Projects/Example/SI-circuit-review

Use the catalog's actual SHA-256, component, pin and model names in ibis-assignments.example.json; replace its zero hashes. Paths are relative to the assignment file. The single-route case ID is route; study exports use their case IDs, with repeatable --case to select a subset (otherwise every case is required). CLI options include --allow-approximations --via-capacitance-pf --via-inductance-nh and --copper-thickness-um. The catalog reads metadata only; KiCad interprets the model. See the KiCad simulator and IBIS guide and the official IBIS 7.1 specification.

Command line and reports

wayricad-si inspect board.kicad_pcb --net "/USB/TxD_OUT"
wayricad-si screen board.kicad_pcb --net "/USB/TxD_OUT" --start U23.42 --end U25.8 --rise-ns 1 --source-ohm 20 --z0-ohm 50 --epsilon-eff 3.2 --output quick-si.json --html quick-si.html

From source use python -m signal_integrity_advisor_plugin.cli. Ordinary Python hands analysis to the compatible installed KiCad runtime. Initial dependency setup may require internet; calculations and reports are local. Omit Z0/Er options to retain automatic unknowns. Use --load-ohm 50 for a resistive load. Exit codes: 0 inventory/screened, 1 error, 2 unresolved, 3 incomplete. Code 0 is not electrical approval.

Retained checks

Impedance & pairs provides editable targets and route/skew review. It does not infer coupled differential impedance by adding two single-ended values. I2C pull-ups checks the range from (VDD − VOL) / IOL and tr / (0.8473 × Cbus).

Troubleshooting and limits

For unresolved routing check exact pad labels, physical continuity and filled zones. For unknown line estimates check continuous adjacent return-plane coverage and the saved Board Setup stackup. Automatic Z0 requires physical dielectric thickness and Er; missing values remain unknown and are never replaced by generic FR-4 dimensions. Follow the report's blocker actions rather than entering a number merely to obtain a result. A saved snapshot needs save/refill and reopen after board changes. Changing a form input clears its prior report.

No full-wave, IBIS-based eye, crosstalk, receiver-capacitance or coupled-line simulation is claimed. Zone corridors are not full plane solutions; effective Er differs from bulk laminate Er. The tool never edits copper.

References: TI High-Speed DSP Systems Design; TI termination discussion; NXP I2C specification. See the packaged README for complete commands and validation.

Return paths and test points

Quick SI now includes the full Return path and Test point records tabs, including descriptor/fixture exports. Return-path reference · Test-point record reference.

Preview and name test points

  1. In Test point labels, load references matching TP* from the originating editor. Use {net} or {ref}: {net} as a template, or edit proposed cells.
  2. Expand Silkscreen and table options for front/back visible values and a set table at explicit X/Y millimetres.
  3. Review changes. Pan/zoom pads and proposed value anchors. Glyphs are approximate; inspect final rotations, mirrors and silk clearances in KiCad.
  4. Apply to editor creates one undo transaction. Changed boards require a fresh review. Undo last apply is guarded against intervening changes; KiCad Undo remains available.

Locked, unconnected and multiple-net footprints are excluded. Saved-board standalone previews cannot apply. PCB value edits do not change schematic values and may be overwritten by a later schematic update.

Protocol suites: low-speed buses through high-speed serial interfaces

Choose among 33 profiles for I2C, SPI, UART, CAN, I2S/TDM, parallel GPIO, SDIO, USB, LVDS, SerDes, PCI/PCIe, DDR, Ethernet and M.2 PCIe/SATA. M.2 alone does not identify an electrical interface. Profile rates and nominal targets are reference information, not compliance limits.

  1. Screen a connected path in Quick SI using actual driver inputs.
  2. Open Protocol suites, choose the interface and Add current Quick SI path. Add each independent route.
  3. Assign P/N roles to a pair or clock/data to a bus, with the same group name. DDR DQ groups use the relevant strobe as clock; coupled strobe behavior remains unmodeled.
  4. Expand Optional engineering budgets for maximum delay (ns), skew (ps), single-ended target deviation (%) or delay/rise ratio. Blank budgets stay unknown.
  5. Run the suite. Inspect checks, selected route and optional eye/step; export local HTML or JSON. Changed assignments/budgets clear the result.

WITHIN_BUDGET applies only to evaluated quantities. REVIEW marks exceeded budgets or mismatched illustrative eye rate. INCOMPLETE retains missing evidence; BLOCKED identifies unusable input, duplicates, different saved revisions or unspecified M.2 interface. Vias/reference transitions are not solved. Independent single-ended routes cannot establish differential impedance, crosstalk or protocol certification.

wayricad-si profiles
wayricad-si screen board.kicad_pcb --net DATA_P --start U1.1 --end U2.1 --role P --group lane0 --output p.json
wayricad-si suite --profile uart --reports route.json --max-delay-ns 1 --html suite.html --output suite.json

The 1 ns budget above is an arbitrary example, not a UART requirement. For pairs add independently screened P and N reports to --reports and choose the actual pair profile. profiles/suite work with ordinary Python, offline. Suite exit codes: 0 within budget, 1 error, 2 blocked, 3 review/incomplete. At most 64 route reports, 16 MiB each. Saved-board changes require reopening and fresh screens; the CLI compares recorded revision hashes but does not reopen their source boards.

Automatic reports and KiCad jobsets

Install the WayriCAD CLI wheel alongside the GUI plugins. In the saved project folder, run wayricad jobs init --preset inventory, then wayricad jobs run --keep-going. Reports, logs and a linked HTML summary go into a fresh reports/wayricad/ run folder. Inventory lists available nets and paths; choose the electrical preset and explicit terminals for numerical analysis.

Use wayricad jobs jobset --output analysis.kicad_jobset to create a native KiCad jobset. Use --merge existing.kicad_jobset --position 1 to insert into an existing sequence, writing a new file. Open the resulting jobset in KiCad's Jobsets manager and run it. Nonzero tool exits and missing reports fail the sequence; successful execution is not engineering approval. Optional SignalIntegrity network interoperability

The CLI can read Touchstone 1.0 S networks using the separately installed Nubis SignalIntegrity 1.5.2 library. Install it explicitly in the Python environment running wayricad-si; no downloads occur during analysis. Reports include the input hash, backend version, frequency grid, complex response, dB magnitude and wrapped phase. Zero response has null dB and phase. Port numbers start at 1; choose to-port 1 for S11.

wayricad-si network channel.s2p --to-port 2 --from-port 1 --output channel.json
wayricad-si line-network route.json --stop-hz 1000000000 --points 1001 --output ideal-line.s2p

Touchstone input must have one explicit option line, positive real common reference impedance, strictly increasing nonnegative frequencies and complete records (at most 32 ports, 10001 records, 16 MiB). Touchstone 2.0 and noise sections are unsupported. The line exporter needs no optional dependency. It accepts complete two-terminal Quick SI reports without zone corridors and exports an ideal lossless uniform line, not extracted board S-parameters. Port 1 is the selected source and port 2 the receiver. Its explicit frequency limit is in Hz, with DC included. Vias, coupling, stubs, source/load and material losses are omitted. The saved report is used without reopening its board. Existing Quick SI eye screening is unchanged; the upstream desktop, calibration and advanced eye workflows are external, not embedded or validated by this bridge. Network processing works offline after dependencies are installed. Run wayricad-si desktop --check to check full desktop imports without opening a window, or wayricad-si desktop [trusted-project.si] to open the original upstream application. Use --python to select its installed Python interpreter. The command waits until the application closes and surfaces errors. Only open trusted upstream projects; their equations and saves use the upstream application's behavior. This exposes the original desktop in a separate process, not a native Quick SI tab. ERL, PZ and IXT retain their upstream console commands. See the packaged README for usage and upstream attribution.

Automatic stackup timing

Choose the net and two pads, then screen the path. Saved stackup data supplies first-order trace and via travel time. APPROXIMATE assumes ideal continuous reference planes and does not solve via reflections or coupling. Route resistance, supported section impedance range and local endpoint estimates remain visible even when a uniform route impedance cannot be calculated. Missing stackup data is reported explicitly. User Z0/Er overrides remain assumptions.

Net picking, cursors and probes

Use Search net names or Select net on board to choose a saved pad, via or track net. Select the two terminals and rerun. In route previews, Probe or Ctrl-click pins geometry coordinates; Clear probes removes them.

Explicit return nets and terminal declarations

Choose the actual return nets with the searchable multi-select Find… control. Optionally select the source and load/receiver return pads; these are declarations, not a solved current loop. Quick PI provides the Return path tab; Quick SI adds an optional Explicit return-path review.

The review covers the whole signal net. Inspect sampled reference coverage, observed signal-via routing layers, reference nets/layers, and nearby return vias with their distances, spans and sampled copper contact. Proximity alone is not continuity; mismatched return nets and missing contact evidence stay unresolved. Filled-zone geometry does not establish return resistance, inductance or current distribution. Save and refill zones before rerunning after edits. Exported HTML retains detailed evidence tables.

Cancellable saved-board analysis

In the normal native sidecar, Screen selected path starts a separate worker for measurement, the optional eye and return review. You can continue using the window. Cancel analysis, an input change or closing the window cancels the owned job; older inputs cannot replace the current result. The worker has a 300-second time budget.

The saved PCB, project and custom rules are checked before and after the run and before export. Reopen Quick SI after changing those files. Analysis does not write the PCB. A legacy live-board window remains synchronous on the UI thread so that unsaved edits are not replaced by a saved-file calculation.

Select between Quick SI and the PCB Editor

Select route in PCB selects the measured route's exact item UUIDs; clicking a route preview item selects that item. Select return nets in PCB selects every checked return net. Missing, ambiguous or incompletely confirmed requests do not leave a partial selection.

Use PCB selection reads only the originating editor. The current signal net is preferred if present; several unrelated selected nets retain the existing inputs. Footprints contribute their pads. Pad roles are updated only when a known source or receiver makes the direction unambiguous. Otherwise choose the terminal roles explicitly. Reverse synchronization clears the previous analysis.

Navigation runs independently from analysis without passing native board objects to a worker thread. Reopen after saved source changes or UUID mismatches. Selection and zoom do not alter PCB geometry.

Resize and read the workspace

Quick SI has a draggable input divider and a horizontal divider above its results table. Enlarge the table to read more rows, or enlarge the route view. Expanded assumptions, return-path and eye controls scroll within the input form.

Independent multi-net study

  1. Open Multi-net study, search/check nets, then Add checked nets to study.
  2. Edit study cases. Assign exact source/receiver pads (Reference.Pad), reference layer and each driver/load assumption. Newly added nets keep terminals blank until you assign direction.
  3. Set comma-separated return nets and source/load return pads per case. These run the whole-signal-net copper/via return audit, including coverage, transitions and pad inventory.
  4. Run, then choose a case above the route view. Errors remain visible while other case results are retained. Export the complete offline comparison.

Route cases are independent. Optional directed local crosstalk pairs add coupled-section estimates; whole-route coupling, simultaneous switching and full-bus qualification remain outside scope. Missing terms remain unresolved. Editing inputs or changing saved PCB/project/custom rules invalidates results.

CLI

wayricad-si study C:/Projects/Example/board.kicad_pcb --config independent-routes.json --output study.json --html study.html
wayricad-si screen C:/Projects/Example/board.kicad_pcb --net DATA --start U1.1 --end J1.1 --return-net GND --return-source U1.3 --return-load J1.3 --html return-review.html

Adapt independent-routes.json using exact net/pad names from inspect. Repeat --return-net for multiple return nets. COMPLETE means independent numerical screens completed; REVIEW and INCOMPLETE require review (CLI exit 3). A return audit is sampled geometry evidence, not proof of a continuous electromagnetic current loop.

Directed local crosstalk

After assigning two or more study cases, choose Configure crosstalk pairs (optional). Explicitly select aggressor and victim case IDs, 10–90% rise time and open-circuit swing. saved-stripline uses the saved homogeneous stackup between two selected immediately adjacent reference layers; both filled planes must cover the pair and a field-margin corridor. Additional same-layer conductors, missing coverage or inhomogeneous dielectric remain unresolved. homogeneous-plane is a hypothetical one-plane model: enter center-to-plane height and Er explicitly.

Run the multi-net study and choose Review crosstalk results. The report lists actual parallel overlaps, gap, widths/thickness, even/odd impedances, NEXT peak, delay and supported/unmodeled route length. Four local ports are matched to sqrt(Zeven × Zodd); independent route source/load settings do not apply. FEXT is zero only in this ideal equal-velocity homogeneous model. Section estimates are not summed into a route waveform. Vias, bends, crossings, broadside coupling, branches and multiple physical-pad loading are not simulated. Finite copper thickness is modeled with boundary panels; adaptive refinement is numerical evidence, not physical qualification.

The offline export includes local NEXT plots and links to the original route cases. See coupled-routes.json for the CLI schema and the plugin guide for model limits and validation. Editing pair settings invalidates previous results; source fingerprints still guard exports.
