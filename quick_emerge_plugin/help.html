Save and load setup or results

Files → Save setup… opens a file chooser in the saved PCB's project folder. Choose a location and name; a missing .json extension is added. Load setup restores geometry, physics, material, mesh, sweep and solver controls. Preview is required again before Run. A changed board asks for confirmation, and region setups must still match a real rule area and signal/reference nets. Missing choices are reported rather than silently replaced. Original schema-1 setups remain readable.

Save results… stores original computed arrays and source evidence in a chosen JSON file. Load results… opens the saved values in the read-only simulation viewer without rerunning the solver. Changed or moved source boards are labelled as historical evidence. Setup and result files are different; use the corresponding command. Cancelling a chooser leaves the current setup untouched.

Open this offline guide with Help or F1 in the workbench. Use the contents to jump to a task.

Quick EMerge is a read-only testing beta for exploratory electromagnetic studies. It reads a saved PCB; it does not write the board or project. Unsaved PCB Editor changes are excluded. Numerical convergence and physical accuracy are not established by a successful run.

Prepare a KiCad board

  1. In KiCad 10 PCB Editor, save a board with closed Edge.Cuts, filled copper zones and an explicit two-layer physical stackup. File > Board Setup opens the stackup settings. Review dielectric thickness and copper separation, then save the board.
  2. Create a board rule area around the subsection. Use the rule-area tool on the right toolbar, place the first corner, name the area in its properties, and complete the polygon by clicking the first corner or double-clicking. Save again. See the KiCad 10 PCB Editor manual for rule areas, zone fills and Board Setup.
  3. In Quick EMerge, choose Saved PCB rule area, load the saved rule areas and select the named area. Choose the F.Cu signal net and B.Cu reference net. Review dielectric separation and the explicit material settings; board stackup geometry does not automatically qualify the material model.

The area outline crops the full two-layer column, regardless of its KiCad keepout permissions. Concavity and holes are retained. Copper crossing the crop can form an ideal boundary port where reference copper covers the full port span; a natural board edge does not create a port. Review the numbered ports in Preview. The region workflow supports 1–8 ideal ports and blocks unsupported geometry, including internal drilled features, unfilled zones, unselected cut conductors and incomplete returns. It does not import a general multilayer board, via barrels, components or interior feeds. The separate via template does not change these limits.

Preview and run

  1. Set geometry in 1 Geometry, materials, boundaries and mesh refinement in 2 Physics, and frequency, output sampling and runtime in 3 Solve. Dimensions are mm, frequency is entered in GHz and impedance in ohms.
  2. Select Preview. Inspect the enclosure, copper, materials and numbered ports, and resolve blocking diagnostics. Save the board first if the design changed.
  3. Select Run simulation. The solver runs separately; Cancel stops it and retains diagnostics. Changing setup clears stale results and requires a new preview.

Frequency, mesh and samples

New studies start with 81 frequency samples, an 81 × 81 field grid, and 2° radiation angles (91 × 181). Existing saved setups keep their frequency and field-grid settings. Under 3 Solve → Output sampling, Use dense sampling selects 81 linear FEM frequencies and an 81 × 81 field grid without changing mesh settings. A 2.4–2.6 GHz linear sweep then has 2.5 MHz spacing; a smaller span gives finer frequency spacing. More frequency solves take longer.

The frequency sweep determines the frequencies evaluated for the network response. The FEM mesh discretizes the model for the solve: refining it affects cost and may affect accuracy. Field grids and radiation angular samples are post-processing samples of the computed fields, not extra FEM solves and not the FEM mesh. Increasing display samples does not prove mesh convergence. Fields remain tied to their recorded frequency and excitation; clicking another chart frequency does not recompute them.

Views and exports

The 2° radiation grid applies to driven antenna and array results. Scattering studies retain a 6° bistatic RCS grid (31 × 61). Local mesh refinement runs the requested fixed number of passes; it does not automatically qualify the full response. The adaptive AAA response tolerance controls frequency sampling, not mesh-convergence acceptance.

Choose 2D / 3D and use Show results for solved fields. Geometry stays available with the toggle off. The field/radiation selector appears only when necessary. More → Viewport controls restores Orbit, Pan, Zoom, Probe and camera settings; Fit restores the view. More → Display settings… controls visibility, projection, color scale and display aspect without changing solver geometry. Probe selects original samples and links views. The Inspector offers pinned samples, extrema and CSV export; a line cut uses nearest original samples and is not continuous interpolation. Radiation radius is normalized relative field magnitude, not gain or physical distance.

More → Result charts shows network results; More → Result summary opens the numerical table. Export… offers Save 2D plot (PNG)…, Save 3D view (PNG)…, Preview report, Export HTML report… and Export PDF report…; PDF requires ReportLab. PNG is a static figure of the current view, while the native 3D view remains interactive. Choosers start in the board project folder and allow a different destination; missing extensions are added. Plots check source/setup before and after rendering and atomically replace the destination only on success. Unavailable fields and reports stay disabled until their data exist. Reports include assumptions, source checks, selected probes and limitations. New results replace previous report state. Source or configuration changes can reject stale exports.

2D and 3D radiation patterns

For a result with radiation samples, choose More → 2D radiation pattern or More → 3D radiation pattern. The view selector also exposes radiation with Show results enabled. Switching 2D / 3D keeps radiation selected and preserves the view cameras.

  • XZ cut: sampled phi = 0° and 180° halves; theta runs from +Z toward +X on the positive half.
  • YZ cut: sampled phi = +90° and −90° halves; theta runs from +Z toward +Y on the positive half.
  • XY azimuth: theta = 90°, with phi from +X toward +Y. A different sampled theta is explicitly labelled as a cone.

The actual sampled plane is printed when a nearby unambiguous plane is used. Unknown samples, missing halves and uncovered directions remain gaps. Both views use the same maximum known stored magnitude across all angles. Radius is relative |E|, not length, dBi gain, efficiency or radiated power. Line segments join stored samples; probes select only original angular samples. Wheel zoom is radial-only in 2D; Fit restores the complete pattern. The native 3D surface supports orbit, pan and zoom.

Export… saves the current 2D pattern or 3D camera image. HTML/PDF reports include the 3D surface, available principal-plane cuts and a separate radiation-probe table verified against original indices, angles and frequency. Cached probe values are recomputed; unknown values remain explicit. Missing radiation leaves these views disabled with an explanation.

Dependencies and troubleshooting

First-open managed setup needs internet, Python 3.10–3.13 and 3 GiB free. Desktop dependencies include a complete wxPython/Matplotlib, VTK and ReportLab environment. EMerge runs in a separate managed environment. Candidate updates pass dependency and compatibility checks before activation; a failed update retains the working runtime. Run settings provide setup/retry and restore-previous-runtime controls. Existing working packages are not upgraded in place.

  • Refinement size-stop messages: the native refiner returns after each scheduled mesh change. Quick EMerge separately checks your reviewed total tetrahedron limit before solving that mesh. A scheduled pass is not a convergence certificate.
  • Empty solved view: preview geometry first, then run a study that produces the selected field or radiation data. Missing samples remain unknown; an empty view is not a zero field.
  • 3D or OpenGL unavailable: check the desktop VTK/OpenGL environment and graphics support; consult the solver and desktop diagnostics. A 2D or chart view may still be available.
  • Setup or solver error: inspect the displayed diagnostic and retained run log, check the interpreter and free space, then retry or restore a compatible previous runtime. Compatibility checks are smoke tests, not proof of convergence.
