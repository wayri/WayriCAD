KiWay Net Hygiene

Scans the open PCB for connectivity and naming issues that are inexpensive to find before a release.

Cross-selection: double-click a finding or use Select on PCB. Pad findings select the pad; net findings select every pad on that net.

Review Cycle

  1. Click Scan after the PCB has been updated from schematic.
  2. Start with errors, then investigate warnings.
  3. Use cross-selection to determine whether the condition is intentional.
  4. Export CSV and document accepted exceptions in the design review record.
FindingMeaningTypical action
duplicate-referenceMore than one footprint has the same reference.Annotate schematic and update PCB.
unconnected-padPad has no assigned net.Connect it or document an intentional NC.
single-pad-netNamed net reaches one pad only.Check test-point/future-option intent.
suspicious-net-nameGenerated or unnamed net.Review source naming.

Limitations

This is a board-level heuristic, not ERC/DRC replacement. Run KiCad DRC before manufacture.
