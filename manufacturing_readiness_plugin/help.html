Workflow

  1. Load or create a reviewed fabricator JSON profile, including the routed copper-to-edge limit.
  2. Audit the current board geometry.
  3. Run JSON DRC and the project jobset.
  4. Resolve failures and inspect command logs.
  5. Build the release ZIP; its manifest records every file hash and gate result.

Safeguards

Packaging is blocked if a capability check fails or remains unknown. The source project is not modified. The saved PCB and live editor must match in every design token; KiCad IPC's temporary version and generator headers directly inside footprints are ignored. Exact saved file bytes are hashed and verified again before release.

Limitations

The manager cannot infer contractual fabrication limits or certify the generated data. Confirm the current quotation, stackup, controlled impedance, material and finish requirements with the fabricator. The routed-edge check covers straight tracks and ordinary vias inside one closed straight Edge.Cuts outline; routed arcs, via padstacks and unsupported outlines remain UNKNOWN. Pads, zones and fabrication tolerances require KiCad DRC and fabricator review.

Pad-hole coverage

Saved-footprint plated and nonplated drill/slot dimensions are audited alongside vias. Custom plated through-hole anchors and offset drills provide conservative annular-ring lower bounds. A bound proves PASS only when it meets the profile; a smaller bound is UNKNOWN unless an exact pad or via already proves FAIL. Explicit per-layer padstacks are included only when every layer has a supported shape and size; other geometry also leaves the annular-ring check UNKNOWN while preserving the independent checks. No applicable objects is N/A, never an infinite passing measurement.

Inputs, units and gate meanings

Save the matching PCB/project and choose that project directory. Fabricator geometry limits use the profile's documented millimetre dimensions; verify drill, annular ring, track, clearance, edge clearance and thickness limits against the actual quotation. Select a project-local jobset when its outputs belong in the release.

StatusAction
PASSThis individual declared check met its limit. Other release gates still apply.
FAILCorrect the design or reviewed fabrication profile and repeat the audit.
UNKNOWNProvide missing evidence or resolve unsupported geometry. Packaging remains blocked.
N/ANo applicable object exists for that check. This is not a measured infinite margin.

Recover an interrupted or blocked run

  • Saved/live mismatch: save the intended board and project in KiCad, then audit again. Unsaved design changes cannot be released from an old snapshot.
  • DRC command failed: inspect its local command log and JSON findings. KiCad's violation exit code is not a successful verification.
  • Jobset output missing: use project-relative output paths inside the captured project, then rerun DRC and the jobset.
  • Evidence became stale: repeat the audit after changes to board, project, profile, jobset or generated artifacts. Rerunning DRC invalidates the old jobset result.
  • ZIP write failed: choose a writable destination and rerun only after confirming the gates remain current. An existing destination is preserved on rejection.

The resulting archive contains verified captured files and a SHA-256 manifest. It does not modify the source project or certify fabrication, assembly or electrical suitability.
