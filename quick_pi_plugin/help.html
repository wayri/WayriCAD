Quick PI: inspect a DC current path

Save the board with current zone fills, choose a net and two pads, enter source volts and sink amperes, then click Run analysis. Analysis runs locally in a cancellable worker and leaves the board unchanged.

  1. Net shows extracted copper, pads and via holes.
  2. Mesh shows the triangles used for the solve.
  3. Results shows absolute voltage, drop, current density, current flow, loss density or pulse risk. Choose a layer, drag to pan and scroll to zoom.

Expand Mesh and material options to set mesh size, via plating and the pulse screen. Compare mesh sizes to assess convergence. Plating defaults to an assumed 25 µm.

Expand Console for help, nets, pads <net> and run pi "Net-(R161-Pad1)" U1.M6 R161.1. Tab cycles completions; Up/Down recall commands. Explicit series components are supported through the documented console syntax.

Export report writes an offline HTML file with seven maps of the selected layer and a paired JSON file with all numerical layers and via records. Dashed links represent explicit component branches.

Interpretation

ΔV/I is path resistance; source V/I describes the operating point. Current density is A/mm²; sheet current is A/mm. Gray floating copper has no connected solution.

The pulse screen is adiabatic energy relative to the selected temperature limit. It excludes cooling and fuse-opening physics. Quick PI solves 2.5D DC conduction, not AC fields or transient inductive behavior. See the full README for assumptions and the Marble regression case.
