Explicit AC Two-Port Impedance

A numerical screening tool for two independent current loops in straight, parallel rectangular copper conductors. It is not an automatic whole-board AC extractor or full-wave simulation. No Palace performance comparison is claimed.

1. Geometry

Enter conductor centre coordinates, width, thickness and common path length in millimetres. Add every outgoing and return conductor that participates in either port. Conductor names must be unique; copper cannot touch or overlap. Geometry is explicit, not inferred from the current PCB selection.

2. Ports And Frequencies

Each port requires a positive and negative conductor. Both port currents enter the positive terminal and return through the negative terminal. Shared returns are supported, but duplicate or reversed copies of the same loop are not independent ports. Supply 1 to 32 distinct positive frequencies in hertz. Unexcited ports have zero net current, not zero local eddy current. Use Load for a saved study; edits invalidate results.

3. Run And Inspect

Run launches a background solve. Cancel discards the result and takes effect between sparse solves, not inside SuperLU factorization. Read both the complex curves and complete table; signed imaginary values are retained. A provisional result has not met the declared mesh/boundary tolerance.

Magnitude plots use logarithmic Hz/ohm scales for all four terms. Hover shows the nearest original complex sample and phase. Pan/zoom with the plot toolbar. Reference loads actual complex samples and adds signed dB differences at common sample frequencies only, without interpolation. See the Markdown contract for the generic reference JSON schema. No Palace data or agreement is invented.

Voltages and currents use RMS phasors, exp(+j omega t); Z is in ohms. Reversing one port changes the signs of transfer impedances without changing the self term.

Math And Performance

The existing cell-centred MQS formulation solves axial vector potential and conductor electric fields with explicit net-current constraints. Z = B transpose times E times length. One sparse LU factorization per frequency and mesh serves both right-hand sides; matrix assembly is not repeated for the second port. Numerical checks cover current balance, reciprocity, positive-semidefinite dissipated power, Joule balance, mesh refinement and magnetic-boundary enlargement. These are numerical checks, not measured accuracy.

Where This Does Not Apply

No bends, changing-width traces, vias, copper zones, dielectric capacitance/loss, radiation, magnetic cores, nonlinear devices, connector resonances or arbitrary return paths are extracted. Electrically large sections are rejected. Relative permittivity participates only in that size guard; it does not add capacitance. Use a qualified distributed/full-wave workflow for those cases, with explicit ports and convergence evidence.

Export And Automation

Save Result writes full normalized inputs, complex matrices, units, checks, numerical work counts and limits to a separate JSON file. It cannot overwrite a loaded input study. The PCB is never modified.

wayricad-pi --ac-ports study.json --output impedance.json --timeout 300

CLI exit codes: 0 converged, 3 provisional, 2 rejected/failed/cancelled. Timeout is cooperative between solves. Complete input contract.
