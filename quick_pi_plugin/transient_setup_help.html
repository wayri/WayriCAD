WayriCAD Quick PI transient load steps

This is an explicit lumped R/L/C model with prescribed current steps or bank-only linear current ramps. It does not derive inductance, capacitance or switching edges from a DC copper solution.

Individual shunt capacitors

In transient setup, select a load and open Shunt capacitors for selected load…. Enter each effective C, ESR and total part + connection ESL. This bank replaces aggregate C/ESR. Choose the actual return to review saved-board candidates; no part is included automatically. Unit-bearing values can prefill, while ESR, ESL and derating remain explicit.

Use a finite prescribed load-current rise for all-inductive feed/shunt paths; an ideal step needing an impulse is rejected. Quick/advanced mode and JSON retain the bank. Capacitor response and HTML tables select per-part internal C voltage, branch current and ESR heat; half-step differences remain evidence, not convergence proof.

Values describe a lumped ideal-return model, not extracted capacitor placement or cross-rail dynamics. Standalone prescribed-current transients only; coupled electrothermal bank stepping and converter control are unsupported.

Quick setup

  1. Choose source and load units in Quick PI, then open the transient study.
  2. Use mΩ, nH, µF and µs in the quick editor. Enter the actual effective capacitance and ESR for each load node. Zero L deliberately disables that inductance term.
  3. A matching feasible single-load DC result can seed one total-path resistor. It is not regulator output resistance: keep the same path out of the branch-R entry to avoid double counting. Multi-load paths and nonlinear drops are not collapsed to an invented resistor.
  4. Set before/after current and the ideal step time, simulation duration and integration step. The initial 100 µs window and 0.1 µs step are editable starting values.
  5. Choose Recommend time step, then Run transient. If the suggested step exceeds the interval budget, shorten the window or revise the model; the tool does not silently coarsen it.
  6. Review voltage/current plots, source/voltage limits, energy/charge balance and the half-step refinement check before export.

The Advanced SI editor retains the full Ω/H/F/s grid. You can switch modes even while required values are missing. Explicit JSON input/output makes the same reviewed model reusable through the CLI.

Aggregate capacitor circuit and equations

For branch supply currents i, capacitor voltages v and prescribed load currents d:

L di/dt + R i + v = Vs·1 + ESR·d
C dv/dt = i − d

L = diag(Lpath) + Lsource·11ᵀ
R = diag(Rpath + ESR) + Rsource·11ᵀ

Kirchhoff current balance gives capacitor current i−d; capacitor voltage integrates that current divided by C. Inductor voltage is L di/dt. Shared source R/L couples the branches. Load-node voltage includes the capacitor ESR jump, so it need not equal the capacitor's stored voltage.

For individual banks, each branch has its own capacitor voltage and charging current, with series ESR/ESL. The aggregate capacitor trace is only a capacitance-weighted mean. The generalized network below retains each branch and finite-ramp forcing.

Individual-bank equations

Let q be charging-positive capacitor currents, v individual internal capacitor voltages, d prescribed load demands and A map capacitor branches to load nodes. Feed currents are i = A q + d. P and Q contain shared/path inductance and resistance.

M = diag(ESL) + Aᵀ P A
R = diag(ESR) + Aᵀ Q A
M q′ + R q + v = Vs·1 − Aᵀ Q d − Aᵀ P d′
diag(C) v′ = q
Vload = Vs·1 − Q i − P i′

Finite linear ramps have explicit slopes d′. Each branch stores its own electric and magnetic energy. Exact algebraic constraints handle ideal branches, and incompatible instantaneous steps are rejected. Shared-source R/L couples load nodes; unknown return or connection paths are not inferred.

Time integration

Initialization is the pre-step DC equilibrium at the Before currents; this is not an arbitrary capacitor-startup or discharge model. The existing solver uses backward Euler, retains ideal step-event samples and compares a half-step run. The setup helper computes finite eigenvalues of the passive descriptor system and suggests twenty samples per fastest e-fold/radian plus at least 1,000 intervals per window. This is a starting heuristic, not proof of convergence. Numerical backward-Euler damping is accounted separately from physical resistor heating.

What is excluded

The bank model supports explicit capacitor ESL and prescribed linear current ramps. Switching converter dynamics, arbitrary current waveforms, constant-power control, source CV/CC transition, 3D time-domain fields and inferred PCB L/C remain unsupported. Supply current budgets are diagnostics, not a simulated current-limit controller. Use reviewed parasitic values and independently check the assumptions.
