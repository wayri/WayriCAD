WayriCAD Quick PI AC / SMPS setup

  1. Choose a quick loop: stacked outgoing/return, side-by-side pair, or symmetric split return.
  2. Enter actual copper width/thickness and surface gap in mm, ripple frequency in kHz and ripple RMS current in A. These are explicit dimensions, not values extracted from the PCB.
  3. Set the detailed length, DC current, rail voltage and copper temperature. Quick setup uses those values without replacing them.
  4. Apply the quick loop to review its conductor/harmonic tables, or Apply quick loop and run. A split return explicitly assigns half the return current to each conductor.
  5. For an SMPS spectrum, use Build SMPS waveform: triangular output ripple takes peak-to-peak amplitude; pulsed input current takes ON current and duty. The solver uses the generated RMS harmonics.
  6. Review the impedance/loss plots, conductor table, energy balance and mesh/air-boundary checks. Export HTML/JSON only after the checks are acceptable.

Model

The AC solver is a current-driven magnetoquasistatic long-straight cross-section model with an explicit balanced return. It resolves skin/proximity redistribution and Joule copper loss. Signed conductor-current multipliers must sum to zero. Zero-current conductors can represent unpowered shields.

For each harmonic, copper loss is the volume integral of |J_RMS|²/σ using RMS quantities; loop impedance and conductor losses follow the existing field solution. DC and distinct harmonic losses add at the declared fixed copper temperature. A quick single-harmonic recipe is not a complete switching waveform.

Limits

Quick layouts replace the conductor/harmonic tables when applied. They do not infer board routes, via transitions, component behavior or return paths. The split-return current fractions are assumptions, not predicted current sharing. No regulator dynamics, converter-device loss, 3D routing field, high-voltage insulation or thermal equilibrium is established. Increase bandwidth and refine mesh/boundary settings as needed; unresolved checks stay explicit.
