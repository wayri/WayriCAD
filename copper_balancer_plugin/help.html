Scroll to zoom, drag to pan, double-click to fit. The density map shows existing and proposed coverage. Targets are ceilings, not guaranteed final coverage.

Fill source zones before planning. Open the output copy, refill zones and run KiCad DRC before fabrication. The source PCB and unsaved editor state are never changed by the PCM workflow.

This engine requires native KiCad 10 Python. Set WAYRICAD_KICAD_PYTHON if discovery fails. Live IPC copper editing and KiCad 11 geometry are not supported yet.

wayricad-copper board.kicad_pcb --layer F.Cu prints a plan summary. Add --output new-board.kicad_pcb to save a new copy. Existing files cannot be replaced.

Full feature and command-line reference

Understand the preview

Rejection counts distinguish region boundaries, density ceilings and combined geometry/clearance checks. Each layer reports tile density range, tiles below target and remaining area deficit. Existing over-target tiles are preserved and reported. Invalid/nonfinite dimensions and impossible geometry measurements stop planning. These are coverage diagnostics, not plating simulation.

Choose dimensions and scope

Size, gap, copper clearance, edge clearance, tile size and band width are millimetres; target is percent copper coverage. Start with one enabled copper layer and a modest shape limit, then compare the density map before adding layers. Manual rectangle bounds use PCB coordinates, not the visible screen rectangle. The saved-copy launcher cannot read a live editor selection.

Step-by-step saved-copy workflow

  1. Save the PCB, close its Edge.Cuts outline and refill its copper zones.
  2. Choose uniform thieving, local density balance or edge bands. Choose shape, lattice and layers; expand density settings only when needed.
  3. Preview and inspect rejected sites, existing over-target tiles and remaining area deficits. A ceiling does not promise that every tile reaches it.
  4. Save balanced copy to a new filename. Open that copy in KiCad, refill zones and run DRC.

If the result is empty or saving fails

  • No candidates: check enabled layers and rectangle coordinates, then inspect boundary, density and clearance rejection counts. Do not reduce clearance below the design requirements to force coverage.
  • Unfilled or outdated geometry: refill and save the source PCB, then create a new preview.
  • Destination already exists: choose a new filename. The tool deliberately refuses to replace source or output boards.
  • Native backend unavailable: use the installed KiCad 10 Python executable through WAYRICAD_KICAD_PYTHON; ordinary Python does not supply pcbnew.
