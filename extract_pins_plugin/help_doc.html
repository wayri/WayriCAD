🔌 WayriCAD Extract Pins Plugin

Version 2.0.0

Extract component data, analyze signal flow, and generate documentation from KiCAD PCBs

✨ Features Overview

📊 Pin Extraction

Extract pin and net information from any component to CSV, Markdown, or JSON formats. Filter by reference, value, net name, or connector type.

🔀 Signal Flow Analysis

Generate source-to-destination signal tables. Trace connections between connectors, ICs, and any components.

📋 IC Signal Charts

Create complete pin-to-destination mapping for ICs. Perfect for debugging and documentation.

📐 SVG Diagrams

Generate self-contained block diagrams. No external dependencies - pure SVG output with color-coded nets.

⚡ Power Net Grouping

Automatically classify GND, VCC, VDD as power nets. Sort and group separately from signal nets.

🔄 Auto-Refresh

Enable auto-refresh to automatically add selected components from PCB to your list in real-time.

🖥️ GUI Usage

Getting Started

  1. Open your PCB in KiCAD PCB Editor
  2. Optionally select some components on the PCB
  3. Go to Tools → External Plugins → Extract Component Pins with GUI
  4. The plugin dialog opens with 4 tabs
Tab 1: Extract Pins

The main extraction tab for component pin data.

Component Selection

  • Auto-Refresh: Enable to automatically add components as you click them on the PCB
  • Refresh Button: Manually get current PCB selection
  • Multi-select: Check to add to existing list instead of replacing
  • Remove: Remove selected items from the list

Filters (Wildcards Supported!)

FilterExampleDescription
ReferenceJ*Match component references
NetSPI_*,I2C_*Filter by net names
Value10k*Filter by component value

Options

  • Ignore Unconnected: Skip pins with no connection
  • Ignore Power Nets: Exclude GND, VCC, VDD, etc.
  • Sort by Net Type: Group signals first, then power
  • Highlight Nets: Color-code nets in Markdown output

Export Buttons

  • Export Selected: Export current list
  • Export J*: Export all connectors
  • Export by Pattern: Use the reference filter pattern
  • Unique Nets: Extract net names only
Tab 2: Signal Flow

Analyze connections between source and destination components.

Usage

  1. Enter Source pattern (e.g., J* for all connectors)
  2. Enter Destination pattern (e.g., U1 for MCU)
  3. Click Preview to see results
  4. Export to CSV, Markdown, or SVG diagram
💡 Tip: Use J* → U* to see all connector-to-IC connections!
Tab 3: IC Signal Chart

Generate complete pin mapping for a specific IC.

Usage

  1. Select an IC from the dropdown (e.g., U1)
  2. Choose whether to include power nets
  3. Click Preview to see all pin connections
  4. Export to CSV, Markdown, or SVG chart

The output shows for each IC pin:

  • Pin number/name
  • Connected net name
  • Destination component and pin
  • Whether it's a power or signal net
Tab 4: Diagrams

Generate self-contained SVG block diagrams.

Diagram Types

  • Component Blocks: Single component with all pins listed
  • Flow Diagrams: Connections between multiple components

Diagrams are pure SVG - no external dependencies needed. Open in any browser or vector editor.

💻 CLI Usage

The plugin includes a full command-line interface for automation and scripting.

Basic Commands

# Show help
python -m extract_pins_plugin --help

# List all components
python -m extract_pins_plugin list board.kicad_pcb

# Extract J* connectors to CSV
python -m extract_pins_plugin extract --refs "J*" --format csv board.kicad_pcb

# Signal flow analysis
python -m extract_pins_plugin signal-flow --source "J*" --dest "U1" board.kicad_pcb

# IC signal chart
python -m extract_pins_plugin ic-chart --ic "U1" --format svg board.kicad_pcb

# Generate diagram
python -m extract_pins_plugin diagram --refs "U1,J1,J2" board.kicad_pcb

CLI Options

OptionDescription
--refs "pattern"Reference patterns (wildcards: *, ?)
--format csv|md|json|svgOutput format
-o, --output fileOutput file (stdout if omitted)
--ignore-powerExclude power nets
--sort-by-typeGroup signals before power
--net-filter "pattern"Filter by net name

🔤 Wildcard Patterns

All filters support wildcards for flexible matching:

PatternMatchesExample Use
J*J1, J2, J10, JCONN1All connectors
U?U1, U2 (not U10)Single digit ICs
*_CLKSPI_CLK, I2C_CLKAll clock signals
J*,U*All J and U componentsMultiple patterns
SPI_*,I2C_*SPI and I2C netsBus filtering

📁 Output Formats

CSV

Clean, one-row-per-pin format. Opens directly in Excel/Google Sheets.

Markdown

Human-readable tables. View in any Markdown viewer or GitHub.

JSON

Structured data for programmatic processing and integration.

SVG

Vector diagrams with:

  • Color-coded net types (signal/power/ground)
  • Component blocks with pin details
  • Connection paths with labels
  • Legend and summary

💡 Tip: Use "Sort by Net Type" to group signal nets first, making it easier to focus on your design's logic connections.

📝 Example Workflows

Document Connector Pinouts

  1. Open plugin
  2. Set Reference filter to J*
  3. Click "Export by Pattern"
  4. Save CSV for spreadsheet, MD for documentation

Debug MCU Connections

  1. Go to "IC Signal Chart" tab
  2. Select your MCU (e.g., U1)
  3. Click "Preview"
  4. Export SVG for visual reference

Trace Signal Path

  1. Go to "Signal Flow" tab
  2. Set Source: J1
  3. Set Destination: U1
  4. Enable "Include Intermediates"
  5. Preview to see complete path
