KiWay Extract Pins

Extract interfaces, test points, TM/TC signals, connectors, peripherals, and board-level signal-flow diagrams from the open PCB and optional KiCad XML netlists.

Basic workflow

  1. Open the PCB and launch KiWay Extract Pins.
  2. Select a schematic/netlist directory when available and set board order, for example DEMO_CTRL,DEMO_SENSOR,DEMO_POWER,DEMO_IO.
  3. Optionally define hierarchical sheet aliases, then click Analyze.
  4. Review the tables and use the Markdown, HTML, CSV, or SVG exports.

Hierarchical sheets

KiWay automatically reads native sheetpath data from KiCad XML netlists. In Sheet Definitions, enter one optional alias rule per line:

Display Name | /hierarchical/path/* | reference wildcard

Channel 1 Power | /Power/Channel1/* | *
Control MCU | * | U1
Connector Sheets | /Interfaces/* | J*

Rules are evaluated from top to bottom and both filters must match. Use * to ignore one filter. The right side of the tab previews the resolved sheet, native path, component count, and references after analysis. Sheet information is included in TM/TC, test-point, connector, peripheral, and component exports.

Signal Flow tab

Use comma-separated wildcard reference filters. For example, Sources J*,U1 and Destinations U*,J2 finds connector/IC paths. Enable Show pass-through parts to keep intermediate footprints. Power nets are excluded by default.

Label examples

DEMO_CTRL_DEMO_SENSOR_SIGNAL_SPI1_CLK_1_TD is interpreted as a board-to-board telemetry-digital signal. Supported identifiers are TM, TC, TA, TD, CA, and CD.

Common issues and fixes

IssueResolution
Sheets show only RootExport an XML netlist from Schematic Editor and select its directory. PCB data alone may not contain hierarchical paths.
A sheet alias does not applyClick Validate Rules; check path slashes and remember that both path and reference filters must match.
No interfaces or pathsSave the PCB, confirm pads have net names, and check wildcard filters.
No IC functionAdd pin-function data to the XML netlist.
Graph import errorInstall networkx in KiCad's Python environment.
Blank chart previewUse SVG exports; native matplotlib preview is optional.
