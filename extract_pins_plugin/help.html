KiWay Extract Pins

Extract interfaces, test points, TM/TC signals, connectors, peripherals, and board-level signal-flow diagrams from the open PCB and optional KiCad XML netlists.

Basic workflow

  1. Open the PCB in PCB Editor and launch KiWay Extract Pins from Tools or the toolbar.
  2. Enter the schematic/netlist directory when available and set board order, for example DEMO_CTRL,DEMO_SENSOR,DEMO_POWER,DEMO_IO.
  3. Click Analyze, review Interfaces, Test Points, TM/TC, and Board Pins.
  4. Use Export Markdown, Export HTML, or Export CSV for ICD and software/test deliverables.

Signal Flow tab

Use comma-separated wildcard reference filters. For example, Sources J*,U1 and Destinations U*,J2 finds connector/IC paths. Enable Show pass-through parts to keep intermediate footprints in the flow. Power nets are excluded by default; enable Include power when documenting rails.

Flow CSV contains source and destination pins, net type, protocol, path, and hop count. Flow SVG creates a three-column chart with labeled arrows. Block SVG creates a board/interface map with source board, destination board, net count, and TM/TC or protocol labels.

Label examples

DEMO_CTRL_DEMO_SENSOR_SIGNAL_SPI1_CLK_1_TD is interpreted as a board-to-board telemetry-digital signal. Tokens TM, TC, TA, TD, CA, and CD must be underscore-delimited.

Common issues and fixes

IssueResolution
No interfaces or pathsSave the PCB, confirm pads have net names, and check wildcard reference filters.
No IC functionAdd pin-function fields to the netlist; the PCB reference/value is used as fallback.
Graph import errorInstall networkx in KiCad's Python environment.
Blank matplotlib previewInstall matplotlib; SVG and table exports do not require it.
Power dominates the chartLeave Include power disabled, or filter power rows in Board Pins.
Intermediate part is missingEnable Show pass-through parts and ensure it shares the same named net.
