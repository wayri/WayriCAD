KiWay Pin Extractor

The extractor is a modeless PCB Editor window. Keep it open while selecting components, reviewing pin rows, and locating nets on the board.

Annotated interface walkthrough

This image uses the same tabs, field names, modes, and actions as the installed window.

Pin Extraction

  1. Open a PCB and launch KiWay Pin Extractor. No initial selection is required.
  2. Choose PCB selection, Wildcard filters, or Selection + filters. Combined mode forms a de-duplicated union.
  3. Leave Follow PCB selection enabled and click footprints in PCB Editor. The modeless window adds them to the Selection basket.
  4. Optionally enter comma-separated reference patterns such as J*, U1, P?, net patterns such as CAN_*, 28V*, and a value pattern.
  5. Choose whether to hide unconnected pins or power/ground nets, then click Preview Extraction.
  6. Double-click a preview row to select its footprint and highlight its net on the PCB.
  7. Click Export Preview... and choose CSV or Markdown. Export uses the exact reviewed data, not a new implicit selection.
Connector shortcut: Use connector preset (J*) switches to wildcard mode, applies J*, and immediately refreshes the preview.

Visual Block Diagrams

  1. Open 4 Block Diagrams and enter references or wildcards, or click Use Extraction Preview.
  2. Select Combined, Signals only, or Power only.
  3. Click Refresh Visual Preview. The self-contained SVG is rendered inside the plugin window.
  4. Click Export This SVG... to save exactly the displayed diagram.

2 Signal Flow creates source-to-destination tables. 3 IC Signal Chart maps one IC pin to every connected destination. Both remain available for focused exports.

Interboard and Harness Work

Multi-project inputs, sheet aliases, TM/TC extraction, cross-link rules, harness generation, and full ICD reports are separated into Tools > External Plugins > KiWay Interboard & Harness. This keeps ordinary pin extraction small while retaining the complete system workflow.

  1. Select the directory containing KiCad XML netlists and enter board order such as DEMO_CTRL,DEMO_SENSOR,DEMO_POWER,DEMO_IO.
  2. Analyze, then review Interfaces, Test Points, TM/TC, Board Pins, and Signal Flow.
  3. Use sheet alias rules in the form Display Name | /hierarchical/path/* | reference wildcard.
  4. Import other board CSV/Markdown documents and build exact, normalized, wildcard, or regex cross-links.
  5. Export the ICD, link tracker, flow SVG, block SVG, or harness SVG.

Integrated Dependency Manager

Open Dependencies... from Interboard & Harness to inspect the active KiCad Python runtime, pip, all suite packages, and required, recommended, or optional Python dependencies.

  1. Verify that the displayed executable is KiCad's bundled Python.
  2. Review missing packages and feature impact.
  3. Use Install Recommended or select rows for Install Selected.
  4. Approve the exact pip command. Installation targets KiCad's user-site.
  5. Restart PCB Editor after installation.
Standalone checks: do not manually register an ActionPlugin from bare KiCad Python. Use kiway dependencies, compile checks, or the integrated manager.

Command-Line Interface

The CLI runs outside KiCad and supports deterministic output, config files, batch directories, and machine-readable diagnostics.

kiway --help
kiway dependencies
kiway dependencies --install --dry-run
kiway inspect design.xml --format json
kiway extract design.xml --output pins.csv --format csv
kiway extract ./projects --batch --sheet-aliases aliases.txt --format json
kiway crosslink board-a.csv board-b.md --rules rules.txt --format json
kiway validate design.xml --diagnostics json
kiway report design.xml --format html --output report.html
kiway report design.xml --format svg --output architecture.svg
kiway benchmark --nets 2000 --iterations 5
kiway test

Use --config config.json for defaults; command-line flags override config values. Exit codes are 0 success, 1 runtime failure, 2 usage/input error, and 3 validation findings.

Troubleshooting

SymptomResolution
PCB selection does not appearEnable Follow PCB selection, click a footprint rather than a track, or click Refresh from PCB.
No preview rowsCheck the selected source mode and clear restrictive net/value filters.
Diagram is emptyUse connected component references and choose Combined before narrowing by connection type.
Only Root sheet appearsUse a KiCad XML netlist; PCB data alone does not contain schematic hierarchy.
Too many cross-linksExclude power and narrow wildcard/regex rules. Ambiguous matches are retained for review.
Missing HTML featuresOpen Dependencies and install recommended packages into KiCad's user-site.
Engineering review remains required: generated tables and diagrams do not replace ERC, DRC, or resolution of ambiguous cross-board links.
