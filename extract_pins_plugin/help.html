KiWay Extract Pins

Extract interfaces, test points, TM/TC signals, connectors, and peripheral information from the open PCB and optional KiCad XML netlists.

Use

  1. Open the PCB in PCB Editor and launch KiWay Extract Pins from Tools or the toolbar.
  2. Enter the schematic/netlist directory when available.
  3. Enter board order, for example DEMO_CTRL,DEMO_SENSOR,DEMO_POWER,DEMO_IO.
  4. Click Analyze, review interfaces, test points, and TM/TC rows, then export Markdown, HTML, or CSV.

Label examples

DEMO_CTRL_DEMO_SENSOR_SIGNAL_SPI1_CLK_1_TD is interpreted as a board-to-board telemetry-digital signal. Tokens TM, TC, TA, TD, CA, and CD must be underscore-delimited.

Common issues

  • No interfaces: save the PCB, provide a valid XML netlist, and check that pads have net names.
  • No IC function: add pin-function fields to the netlist or use the PCB reference/value as the fallback.
  • Graph import error: install networkx in the Python environment used by KiCad.
  • Blank visualization: install matplotlib; table exports do not require it.
