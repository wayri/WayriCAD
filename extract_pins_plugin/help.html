KiWay Extract Pins

Annotated interface walkthrough

The numbered cues below match the visible workflow in the plugin. A preview is the review evidence; committing or exporting is the final step.

Turn a KiCad PCB and optional XML netlists into reviewable interface tables, test-point traces, TM/TC registers, cross-project link trackers, harness diagrams, and controlled documentation.

PCB cross-selection: activate a row in Board Pins or Component Export to select the corresponding PCB item and highlight its net. The report remains the working index while PCB Editor remains the source of truth.

Workflow Map

Desktop Workflow

  1. Open a PCB, then launch KiWay Extract Pins.
  2. Choose the directory containing KiCad XML netlists when sheet hierarchy or pin functions matter. A saved PCB alone still supports board-pin, connector, and test-point extraction.
  3. Set Board order, for example DEMO_CTRL,DEMO_SENSOR,DEMO_POWER,DEMO_IO, then click Analyze.
  4. Review Interfaces, Test Points, TM/TC, and Board Pins. Activate an item to cross-select it in PCB Editor; use Highlight Net for a complete net.
  5. Export Markdown, HTML, CSV, interface SVG, flow SVG, or a cross-project harness SVG.

Sheet Aliases

KiCad XML sheetpath values retain the full hierarchy. In Sheet Definitions, enter one rule per line:

Display Name | /hierarchical/path/* | reference wildcard
Channel 1 Power | /Power/Channel1/* | *
Control MCU | * | U1
Connector Sheets | /Interfaces/* | J*

Rules are evaluated top to bottom. Both path and reference filters must match; use * when either filter should not constrain a rule. Validate Rules before publishing an ICD.

Cross-Project Linking

  1. Open Cross-Link, import CSV/Markdown pin documents for each board, or add the current PCB.
  2. Keep exact and normalized matching enabled for ordinary names. Normalization tolerates case, spaces, hyphens, underscores, and slashes.
  3. Add ordered wildcard or regex rules for naming boundaries, then Build Cross-Links. Ambiguous endpoints are deliberately retained rather than arbitrarily paired.
  4. Export the tracker or generate a harness SVG.

WildcardBoard prefixes | wildcard | DEMO_CTRL_* | DEMO_SENSOR_*The captured signal suffix must agree.

TM/TC Labels

DEMO_CTRL_DEMO_SENSOR_SIGNAL_SPI1_CLK_1_TD resolves to source DEMO_CTRL, destination DEMO_SENSOR, signal SPI1_CLK_1, and telemetry digital TD. Supported tokens: TM, TC, TA, TD, CA, and CD.

Command-Line Interface

The kiway command runs outside KiCad for repeatable CI and batch documentation. Run kiway --help or kiway <command> --help for every option.

kiway inspect design.xml --format json
kiway extract design.xml --output icd.md --format markdown
kiway crosslink board-a.csv board-b.md --rules rules.txt --format json
kiway validate design.xml --aliases sheets.txt --diagnostics json
kiway report design.xml --format html --output report.html
kiway benchmark --nets 2000 --iterations 5
kiway test
CommandUse
inspectParse a project/netlist and emit a deterministic summary.
extractExtract pins, connectors, test points, TM/TC, and sheet metadata.
crosslinkMatch imported projects with exact, normalized, wildcard, or regex rules.
validateReturn machine-readable diagnostics; exit code 3 means validation findings.
reportGenerate Markdown, HTML, CSV, JSON, or SVG artifacts.
benchmarkRun deterministic synthetic scaling checks.
testRun the KiWay unit-test suite.

Commands support deterministic JSON and --config config.json. Exit codes: 0 success, 1 operational error, 2 usage/input error, 3 validation failed.

Troubleshooting

SymptomResolution
Only Root sheet appearsExport a KiCad XML netlist from Schematic Editor and select its directory. PCB data alone does not carry hierarchy.
Alias does not applyValidate Rules, check slash direction, and confirm both path and reference patterns match.
Too many linksDisable power matching and narrow wildcard/regex rules. Resolve each ambiguous row before release.
No cross-selectionSave/reload after a major PCB update. Select a concrete Board Pins or Component Export row, not an imported-document row.
Graph import errorInstall networkx in the Python environment executing the CLI or KiCad plugin.
Engineering note: generated trackers and diagrams are review artifacts. Run KiCad ERC/DRC and review ambiguous system-level links before manufacturing or release.
