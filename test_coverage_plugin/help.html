KiWay Test Coverage Planner

Reports board-net access through TP/TestPoint footprints.

Use

  1. Open the board and launch the plugin.
  2. Click Scan to list every named board net.
  3. Review covered and missing nets, then export CSV for fixture planning.

Detection

A footprint is treated as a test point when its reference begins with TP or its value contains TESTPOINT.

Common issues

  • Test point missing: use a TP reference or a value containing TestPoint.
  • Net shows missing: update PCB connectivity and check the TP pad net assignment.
  • Too many nets: filter the exported CSV by interface or manufacturing relevance.
